# Metric Glossary — คำอธิบายศัพท์การเงินบนหน้าจอ

ทะเบียนกลางของ**คำอธิบายภาษาไทยสั้น ๆ** ที่กำกับทุกค่าการเงินบนหน้าจอ (ตาม BR-MVP-03 และ R16)
— การ์ดอ้างชื่อ metric จากที่นี่ ห้ามเขียนคำอธิบายใหม่กระจายอยู่ตามการ์ด

## กติกา

1. ทุกค่าที่ปรากฏบนหน้าจอต้องมีแถวในตารางนี้ **ก่อน** การ์ดที่แสดงมันจะขึ้น 🟢 Ready
2. คำอธิบายยาวไม่เกินสองประโยค ภาษาที่คนไม่ได้เรียนการเงินอ่านรู้เรื่อง ไม่มีสูตร (สูตรอยู่ในการ์ดของชั้นคำนวณ)
3. i18n key ล้อกัน (`metric.<slug>.label` / `metric.<slug>.hint`) มีทั้ง TH และ EN
4. แก้คำอธิบาย = แก้ที่นี่ที่เดียว ทุกจอที่แสดงค่านั้นเปลี่ยนตาม (parity ตาม R13)

## ทะเบียน (ชุดเฟส 0–1)

| Metric | ป้ายไทย | คำอธิบาย (hint) | i18n key | นิยามเชิงสูตร |
| --- | --- | --- | --- | --- |
| End Balance | มูลค่าสุดท้าย | เงินตั้งต้นจะกลายเป็นเท่าไรเมื่อสิ้นสุดช่วงเวลาที่เลือก | `metric.endBalance` | BR-ENG-04 |
| CAGR | ผลตอบแทนต่อปีแบบทบต้น | อัตราเติบโตเฉลี่ยต่อปีถ้าเงินโตเท่ากันทุกปีจนได้ผลลัพธ์เดียวกัน ยิ่งสูงยิ่งดี | `metric.cagr` | BR-ENG-05 |
| Stdev | ความผันผวนต่อปี | ผลตอบแทนแกว่งจากค่าเฉลี่ยมากแค่ไหน ยิ่งสูงพอร์ตยิ่งเหวี่ยงแรง | `metric.stdev` | BR-ENG-06 |
| Best Year | ปีที่ดีที่สุด | ผลตอบแทนของปีปฏิทินที่ดีที่สุดในช่วง (นับเฉพาะปีเต็ม) | `metric.bestYear` | BR-ENG-12 |
| Worst Year | ปีที่แย่ที่สุด | ผลตอบแทนของปีปฏิทินที่แย่ที่สุดในช่วง (นับเฉพาะปีเต็ม) บอกว่าปีร้าย ๆ เจ็บแค่ไหน | `metric.worstYear` | BR-ENG-12 |
| Max Drawdown | ช่วงขาดทุนสูงสุด | จากจุดสูงสุดเคยตกลงมาลึกที่สุดกี่เปอร์เซ็นต์ ก่อนจะกลับขึ้นไปเท่าเดิม | `metric.maxDrawdown` | BR-ENG-07 |
| Recovery Time | เวลาฟื้น | ใช้เวลากี่เดือนจากจุดต่ำสุดกว่าจะกลับมาเท่าจุดสูงสุดเดิม | `metric.recoveryTime` | BR-ENG-07 |
| Sharpe Ratio | Sharpe | ผลตอบแทนส่วนที่เกินจากการฝากแบบไร้ความเสี่ยง ต่อหนึ่งหน่วยความผันผวน ยิ่งสูงยิ่งคุ้มความเสี่ยง | `metric.sharpe` | BR-ENG-09 |
| Sortino Ratio | Sortino | คล้าย Sharpe แต่ลงโทษเฉพาะการแกว่งขาลง เหมาะกับคนที่กลัวขาดทุนมากกว่ากลัวความเหวี่ยง | `metric.sortino` | BR-ENG-10 |
