# Validation Glossary — folio-lab

ทะเบียนกลางของข้อความ validation/error ที่ผู้ใช้เห็น — **การ์ด story ต้องอ้างรหัสจากที่นี่ ห้ามคิดข้อความใหม่ในการ์ด**

## กติกา

1. **หนึ่งความหมาย = หนึ่งรหัส** — ถ้าความหมายตรงกับรหัสที่มีอยู่ ให้ใช้ซ้ำ อย่าสร้างรหัสใหม่
2. ข้อความเป็น**ภาษาไทย** เขียนแบบบอกวิธีแก้ ไม่ใช่บอกว่าผู้ใช้ผิด และต้องผ่านกฎ copy (R12):
   ห้ามศัพท์ implementation (`API`, `provider`, `cache`, `endpoint`, `stub`, `fetch`, …), ห้าม `—`
3. เพิ่ม/แก้กฎ gate เมื่อไหร่ ต้องขยับพร้อมกันสี่ที่ (R7): **BR** ในการ์ด · **AC** แถวที่ตรงกัน ·
   **ตาราง Validation** ของการ์ด · ไฟล์นี้
4. รหัสที่เลิกใช้ **ห้ามลบ** — ทำเครื่องหมาย `♻ เลิกใช้ (แทนด้วย V-xxx)` เพื่อไม่ให้การ์ดเก่าอ้างถึงของที่หายไป
5. คีย์ i18n ของแต่ละรหัสตั้งชื่อล้อกัน (`validation.<slug>`) และต้องมีทั้ง TH และ EN

## รหัสที่คาดว่าจะต้องมี (ร่างจาก roadmap — ยังไม่ผูกการ์ด)

รายการนี้เป็นเพียงตัวช่วยจำตอนเขียน epic แรก ยังไม่ถือว่าลงทะเบียนจนกว่าจะมีการ์ดอ้างถึงและย้ายขึ้นตารางบน

- น้ำหนักพอร์ตรวมไม่เท่ากับ 100%
- ไม่ได้ระบุสัญลักษณ์/สินทรัพย์เลย
- สัญลักษณ์ที่กรอกไม่พบข้อมูล
- ช่วงเวลาที่เลือกยาวกว่าข้อมูลที่มี
- วันที่เริ่มอยู่หลังวันที่สิ้นสุด
- เงินตั้งต้นต้องมากกว่า 0
- โหลดข้อมูลราคาไม่สำเร็จ (ลองใหม่ได้)
- ลิงก์ที่เปิดมามีค่าตั้งค่าไม่ถูกต้อง
