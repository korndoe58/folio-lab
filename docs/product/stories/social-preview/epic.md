# Epic: การ์ดพรีวิวตอนแชร์ลิงก์ (social-preview)

**Status:** ✅ Done (S20) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Roadmap:** งานข้ามเฟส เกิดหลัง S19 · **Session:** S20 author · S20 implement

> **อ่านก่อน (TL;DR)**
> - วันนี้เวลาเอาลิงก์ folio-lab ไปวางใน LinkedIn / Slack / LINE จะขึ้นเป็น**กล่องเทาเปล่า ๆ ที่มีแค่คำว่า
>   "folio-lab"** เพราะหน้าเว็บไม่ได้ส่งข้อมูลพรีวิวออกไปเลย
> - คนที่เห็นลิงก์จึงไม่รู้ว่าเครื่องมือนี้ทำอะไร และไม่มีเหตุผลให้กด
> - epic นี้ทำให้ลิงก์ที่แชร์แสดง **ภาพหน้าจอผลลัพธ์จริง + ประโยคเดียวที่บอกว่าเครื่องมือนี้ตอบคำถามอะไร**
> - พร้อมกันนั้น **แก้คำโฆษณาที่เกินจริง** — หน้าเว็บบอกว่ารองรับ "กองทุนไทย" แต่ PD-012 พักเรื่องนี้ไว้
>   เพราะแหล่งข้อมูลยังไม่มีให้ · การ์ดพรีวิวจะยิ่งขยายคำอ้างนั้นออกไปกว้างขึ้น จึงต้องแก้ในรอบเดียวกัน

## §1 ปัญหา (Problem)

เจ้าของ project เอาลิงก์ไปแชร์เพื่อให้คนอื่นดูผลงาน แต่สิ่งที่คนเห็นคือกล่องสีเทาที่มีแค่ชื่อ ไม่มีภาพ
ไม่มีคำอธิบาย — ลิงก์ที่ควรเป็นจุดแข็งกลับดูเหมือนลิงก์เสีย และไม่มีใครกดเข้ามา

ซ้อนกับปัญหาที่สอง: ประโยคแนะนำบนหน้าแรกและข้อมูลพรีวิวของหน้าเว็บบอกว่าเครื่องมือนี้รวม
"กองทุนไทย" ได้ ทั้งที่ยังทำไม่ได้จริง คนที่กดเข้ามาแล้วลองค้นกองทุนจะเจอช่องว่างทันที
ซึ่งทำลายความน่าเชื่อถือมากกว่าการไม่พูดถึงตั้งแต่แรก

## §2 ผู้ใช้ (Persona)

- **คนที่เห็นลิงก์ที่ถูกแชร์** (recruiter, เพื่อนร่วมวงการ, นักลงทุนรายย่อย) — ยังไม่เคยเข้าเว็บ
  ตัดสินใจภายในไม่กี่วินาทีว่าจะกดหรือไม่ จากภาพและข้อความที่แพลตฟอร์มดึงไปแสดงเท่านั้น
- **เจ้าของ project** — เป็นคนแชร์ลิงก์ และเป็นคนรับผลถ้าคำโฆษณาไม่ตรงกับของจริง

## §3 คุณค่า & ตัววัดความสำเร็จ (Value & Success Metric)

- **คุณค่า:** ลิงก์ที่แชร์ออกไปอธิบายตัวเองได้ และคำอธิบายนั้นตรงกับสิ่งที่เครื่องมือทำได้จริง
- **ตัววัด (ต้องวัดได้):**
  - เครื่องมือตรวจพรีวิวของ LinkedIn (Post Inspector) แสดง **ภาพ + หัวเรื่อง + คำอธิบาย** ครบสามอย่าง
  - ภาพพรีวิวมีขนาด **1200 × 630** และเป็นภาพหน้าจอผลลัพธ์จริงของแอป ไม่ใช่ภาพจำลอง
  - ข้อความที่ผู้ใช้เห็นทั้งเว็บ **ไม่มีคำว่า "กองทุนไทย"** ในความหมายว่ารองรับแล้ว
- **หลักที่ยึด:** P4 แชร์/ทำซ้ำผลได้ · P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## §4 ขอบเขต (Scope)

**อยู่ในขอบเขต:**
- [ ] ข้อมูลพรีวิว (Open Graph + Twitter card) ของทั้งเว็บ ตั้งที่ layout ราก
- [ ] ภาพพรีวิว 1200 × 630 จากหน้าจอผลลัพธ์จริง เก็บเป็นไฟล์ใน `public/`
- [ ] แก้ประโยคแนะนำทั้งไทยและอังกฤษ ให้ตรงกับสิ่งที่ ship แล้ว
- [ ] เทสต์ยืนยันว่าข้อมูลพรีวิวถูกส่งออกจริงบน build จริง

**นอกขอบเขต (ตั้งใจตัด):**
- [ ] **ภาพพรีวิวแยกรายหน้า** — ทุกหน้าที่แชร์จริงคือหน้าแรก ทำรายหน้าเพิ่มความซับซ้อนโดยไม่มีคนใช้
- [ ] **พรีวิวภาษาอังกฤษแยก URL** — ตอนนี้หนึ่ง URL เสิร์ฟทั้งสองภาษา ภาษาสลับฝั่ง browser เท่านั้น
      ตัวดึงข้อมูลของแพลตฟอร์มไม่รัน JavaScript จึงเห็นภาษาไทยเสมอ · จะทำต้องเปลี่ยนโครงสร้าง route
      ซึ่งเป็นงานคนละขนาดและต้องมี PD ของตัวเอง
- [ ] **ไอคอนเว็บ (favicon)** — ยังเป็นของเริ่มต้นจาก Next.js อยู่ แต่เป็นคนละเรื่องกับการ์ดพรีวิว
- [ ] **เปิดใช้กองทุนไทย** — ยังติดที่คีย์ ก.ล.ต. ตาม PD-012 · epic นี้แก้คำอธิบาย ไม่ได้แก้ความสามารถ

## §9 กฎร่วมของ epic (Shared Rules)

- **หนึ่งข้อความ สองที่** — ประโยคแนะนำอยู่ในชั้น i18n (`app.tagline`) ส่วนคำอธิบายพรีวิวเป็นข้อความ
  คงที่ฝั่งเซิร์ฟเวอร์ที่ i18n เข้าไม่ถึง ทั้งสองต้องพูดตรงกัน และต้องแก้พร้อมกันเสมอ
- **คำอธิบายพรีวิวพูดได้เฉพาะสิ่งที่ ship แล้ว** — ถ้าความสามารถไหนยังพักอยู่ ห้ามเอ่ยถึงในลักษณะที่
  อ่านแล้วเข้าใจว่าใช้ได้แล้ว
