# Epic: แคตตาล็อกสินทรัพย์ (asset-catalog)

**Status:** ✅ Done (S16b) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Roadmap:** งานข้ามเฟส เกิดหลังปิดเฟส 2 · **Session:** S16b
**ลำดับ:** แทรกก่อน S17 เพราะเป็นข้อจำกัดที่ขวางการใช้งานจริงของทุกอย่างที่ ship ไปแล้ว

> **อ่านก่อน (TL;DR)**
> - เครื่องมือนี้เทียบได้ 3 พอร์ต ใส่เงินเข้าออกได้ ปรับสมดุลได้ 5 แบบ — แต่มีสินทรัพย์ให้เลือก **10 ตัว**
> - คนที่ไม่รู้ตัวย่ออยู่แล้วจึงตั้งพอร์ตของตัวเองแทบไม่ได้เลย ความสามารถที่สร้างมาสามเฟสถูกขังไว้ด้วยข้อนี้
> - epic นี้ขยายเป็น **100 ตัว (ไทย 50 · ต่างประเทศ 50)** และทำให้กล่องเลือก**แบ่งหมวดหมู่**ใช้งานได้จริง
> - ไม่แตะชั้นคำนวณเลยแม้แต่บรรทัดเดียว — ทุกค่าที่ ship ไปแล้วต้องเท่าเดิมทุกหลัก

---

## §1 ปัญหา (Problem)

รายการแนะนำวันนี้มี 10 ตัว มาจาก S2 (5 ตัวต่างประเทศ ใช้พิสูจน์ว่าชั้นข้อมูลทำงาน) และ S11
(5 ตัวไทย ใช้พิสูจน์ว่า `.BK` กับการแปลงค่าเงินทำงาน) — ทั้งสองชุดถูกเลือกมาเพื่อ**พิสูจน์ระบบ**
ไม่ใช่เพื่อ**ให้คนใช้เลือก** และไม่เคยถูกขยายอีกเลยตลอดสามเฟส

ผลคือผู้ใช้ที่เปิดเว็บมาแล้วอยากลองพอร์ตของตัวเองต้องรู้ตัวย่อที่ถูกต้องมาก่อน (รวมทั้งต้องรู้ว่า
หุ้นไทยต้องเติม `.BK`) มิฉะนั้นก็ได้แค่กดพอร์ตตัวอย่างดู ซึ่งไม่ใช่การใช้เครื่องมือ

## §2 ผู้ใช้ (Persona)

คนไทยที่ลงทุนเองและอยากรู้ว่าพอร์ตที่ตัวเองถืออยู่จริง ๆ ให้ผลอย่างไรย้อนหลัง — รู้จักหุ้นและกองทุน
ที่ตัวเองถือในชื่อที่คนเรียกกัน (`กสิกร` `ปตท.` `เซเว่น`) มากกว่าในตัวย่อภาษาอังกฤษ

## §3 คุณค่า & ตัววัดความสำเร็จ (Value & Success Metric)

- **คุณค่า:** ปลดล็อกความสามารถที่สร้างมาสามเฟสให้คนที่ไม่ได้จำตัวย่อใช้ได้จริง
- **ตัววัด (วัดได้):**
  1. มีสินทรัพย์ให้เลือก **100 ตัว** แบ่งไทย 50 / ต่างประเทศ 50 และ**ทุกตัวรันได้จริงบนข้อมูลสด**
  2. กล่องที่กางลงมา**แบ่งหมวดพร้อมหัวข้อ** และพิมพ์กรองข้ามหมวดได้
  3. สินทรัพย์ที่ข้อมูลย้อนหลังสั้นบอกปีที่ข้อมูลเริ่ม**ก่อน**ผู้ใช้เลือก ([PD-017](../../decision-log.md))
  4. **ค่าของทุกอย่างที่ ship ไปแล้วไม่ขยับสักหลัก** — เพิ่มของให้เลือก ไม่ใช่เปลี่ยนวิธีคำนวณ
- **หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน (หลัก) · P1 เลขเชื่อถือได้

**ผลของตัววัดเมื่อปิด epic (S16b):**

| # | ตัววัด | ผล |
| --- | --- | --- |
| 1 | 100 ตัว แบ่ง 50/50 และทุกตัวรันได้จริง | ✅ `node scripts/probe-symbols.mjs` รายงาน **ตรง 100 · ไม่ตรง 0 · หาไม่เจอ 0** |
| 2 | กล่องแบ่งหมวดพร้อมหัวข้อ และกรองข้ามหมวดได้ | ✅ 19 หมวด · พิมพ์ `PTT` เหลือหมวดเดียวสามตัว · หมวดที่ว่างหายทั้งหัวข้อ |
| 3 | ตัวข้อมูลสั้นบอกปีก่อนเลือก | ✅ `SCB.BK … ข้อมูลจาก 2022` · ตัวข้อมูลเต็มไม่ถูกกำกับ |
| 4 | ค่าที่ ship ไปแล้วไม่ขยับสักหลัก | ✅ ลิงก์ `assets=` เดิมยัง `$24,884` / `8.64%` · `golden.test.ts` เขียวโดยไม่ถูกแตะ |

## §4 ขอบเขต (Scope)

**อยู่ในขอบเขต:**
- แคตตาล็อก 100 ตัวพร้อมชื่อไทย/อังกฤษ และปีที่ข้อมูลเริ่มของทุกตัว
- หมวดหมู่ที่อ่านรู้เรื่องสำหรับคนทั่วไป และแสดงเป็นหัวข้อในกล่องที่กางลงมา
- ชุดข้อมูลจำลองของสัญลักษณ์เท่าที่ชุดทดสอบต้องใช้
- สคริปต์ตรวจว่าแคตตาล็อกยังตรงกับแหล่งข้อมูลจริง

**อยู่นอกขอบเขต:**
- ค้นหาสินทรัพย์จากแหล่งข้อมูลแบบสด (รายการนี้มากับตัวเว็บตาม BR-CFG-05 เดิม)
- กองทุนรวมไทย — ยังติดคีย์ ก.ล.ต. ตาม [PD-012](../../decision-log.md)
- สัญลักษณ์ที่ขึ้นต้นด้วยตัวเลข (เช่น `1DIV.BK`) — ติดกฎรูปแบบสัญลักษณ์ที่ ship แล้ว ต้องมี PD แยก
- การเปลี่ยนวิธีคำนวณใด ๆ
