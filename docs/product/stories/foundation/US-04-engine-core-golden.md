# US-04: คำนวณผลพอร์ตและค่าความเสี่ยงชุดแรก

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S3) · เส้นทาง: ⚪ → 🟡 → 🟢 → 🔨 → **✅ Done**
**Priority:** P0 · **Session:** S3 · **Roadmap:** [Phase 0 · feature 0.4](../../../ROADMAP.md) · **Route:** ไม่มี (ชั้นคำนวณ) · **Data mode:** จำลอง (ชุดตรึง)

> **ในฐานะ** ผู้ใช้ที่จะตัดสินใจลงทุนจากตัวเลขบนหน้าจอ **ฉันต้องการ** ให้ค่าที่เห็นคำนวณตรงตามนิยามมาตรฐานที่เครื่องมือระดับสากลใช้ **เพื่อที่จะ** เชื่อผลที่ได้และเทียบกับที่อื่นได้

**หลักที่ยึด:** P1 เลขเชื่อถือได้ (หลัก) · P2 เข้าใจได้โดยไม่ต้องจบการเงิน (ทุกค่ามีนิยามเขียนไว้)

## กฎทางธุรกิจ (Business Rules)

| Rule ID | กฎ (สูตรและหน่วยเวลา) | เจ้าของค่า | Priority |
| --- | --- | --- | --- |
| BR-ENG-01 | ผลตอบแทนพอร์ตของเดือนหนึ่ง = ผลรวมของ (น้ำหนักปัจจุบันของแต่ละสินทรัพย์ × ผลตอบแทนของสินทรัพย์นั้นในเดือนนั้น) — น้ำหนักเป้าหมายถูก normalize ให้รวมเป็น 1 ก่อนคำนวณเสมอ (รองรับความคลาด 0.01 ที่ฟอร์มยอมให้ผ่าน) | ชั้นคำนวณ | P0 |
| BR-ENG-02 | น้ำหนักของแต่ละสินทรัพย์**ลอยไปตามผลตอบแทนระหว่างปี** ไม่คงที่ และถูกดึงกลับสู่น้ำหนักเป้าหมายเมื่อปรับสมดุล | ชั้นคำนวณ | P0 |
| BR-ENG-03 | การปรับสมดุลรายปีเกิด ณ สิ้นเดือนธันวาคมของทุกปี โดยตั้งน้ำหนักกลับเป็นน้ำหนักเป้าหมาย ไม่มีค่าธรรมเนียมและไม่มีภาษี | ชั้นคำนวณ | P0 |
| BR-ENG-04 | เส้นมูลค่าพอร์ต: **จุดตั้งต้น (ก่อนเดือนแรกของช่วง) = เงินตั้งต้น** จากนั้นมูลค่า ณ สิ้นเดือน M = มูลค่าจุดก่อนหน้า × (1 + ผลตอบแทนพอร์ตเดือน M) **โดยคูณทุกเดือนรวมเดือนแรกของช่วงด้วย** — ผลตอบแทนของเดือนแรกต้องไม่ถูกข้าม | ชั้นคำนวณ | P0 |
| BR-ENG-05 | ผลตอบแทนต่อปีแบบทบต้น = (มูลค่าสุดท้าย ÷ เงินตั้งต้น) ยกกำลัง (12 ÷ จำนวนเดือน) แล้วลบหนึ่ง โดย **"จำนวนเดือน" = จำนวนผลตอบแทนรายเดือนในช่วง** (พอร์ตอ้างอิง ม.ค. 2012 – มิ.ย. 2026 = 174 เดือน) | ชั้นคำนวณ | P0 |
| BR-ENG-06 | ความผันผวนต่อปี = ส่วนเบี่ยงเบนมาตรฐานของผลตอบแทนรายเดือน × √12 โดยใช้ตัวหาร n−1 (แบบตัวอย่าง) | ชั้นคำนวณ | P0 |
| BR-ENG-07 | ช่วงขาดทุนสูงสุด = ค่าต่ำสุดของ (มูลค่า ณ เดือนนั้น ÷ มูลค่าสูงสุดที่เคยทำได้จนถึงเดือนนั้น) − 1 รายงานพร้อมเดือนที่เริ่มตก เดือนที่ต่ำสุด และเดือนที่กลับมาเท่าจุดสูงสุดเดิม — **ระยะเวลาฟื้น = จำนวนเดือนนับถัดจากเดือนต่ำสุด ไปจนถึงเดือนแรกที่มูลค่ากลับมา ≥ จุดสูงสุดเดิม (นับเดือนที่ฟื้นด้วย)** เช่น ต่ำสุด ก.ย. 2022 ฟื้น มี.ค. 2024 = 18 เดือน | ชั้นคำนวณ | P0 |
| BR-ENG-08 | ถ้าจนถึงเดือนสุดท้ายยังไม่กลับถึงจุดสูงสุดเดิม ให้รายงานว่ายังไม่ฟื้น ไม่ใช่รายงานเวลาฟื้นเป็นศูนย์ | ชั้นคำนวณ | P0 |
| BR-ENG-09 | Sharpe = (ค่าเฉลี่ยของผลตอบแทนส่วนเกินรายเดือน ÷ ส่วนเบี่ยงเบนมาตรฐานของผลตอบแทนส่วนเกินรายเดือน **ตัวหาร n−1 ตาม BR-ENG-06**) × √12 โดยผลตอบแทนส่วนเกิน = ผลตอบแทนพอร์ต − อัตราปราศจากความเสี่ยงของเดือนนั้น | ชั้นคำนวณ | P0 |
| BR-ENG-10 | Sortino ใช้สูตรเดียวกับ Sharpe แต่ตัวหารเป็นส่วนเบี่ยงเบนเฉพาะด้านขาดทุน คือรากที่สองของค่าเฉลี่ยกำลังสองของผลตอบแทนส่วนเกินที่ติดลบ โดยหารด้วยจำนวนเดือนทั้งหมด (ไม่ใช่เฉพาะเดือนที่ติดลบ) × √12 | ชั้นคำนวณ | P0 |
| BR-ENG-11 | อัตราปราศจากความเสี่ยงในเฟสนี้ใช้ **ชุดค่ารายเดือนที่ freeze ไว้** ตาม BR-FND-03 (T-Bill 3 เดือนสหรัฐ บันทึกมาพร้อม fixture — ดู ROADMAP ภาคผนวก A) ฟังก์ชันรับชุดนี้เป็นข้อมูลนำเข้าเช่นเดียวกับผลตอบแทน ไม่ฝังค่าไว้ในโค้ด | ชั้นคำนวณ | P0 |
| BR-ENG-12 | ผลตอบแทนรายปี = ผลคูณต่อเนื่องของ (1 + ผลตอบแทนรายเดือน) ของเดือนในปีนั้น แล้วลบหนึ่ง ปีที่มีเดือนไม่ครบให้คำนวณจากเดือนที่มีและระบุว่าเป็นปีไม่เต็ม — **ปีที่ดีที่สุด/แย่ที่สุดพิจารณาเฉพาะปีเต็มเท่านั้น** (ตามแนวทางของต้นแบบ) | ชั้นคำนวณ | P0 |
| BR-ENG-13 | ทุกฟังก์ชันรับผลตอบแทนรายเดือนเป็นข้อมูลนำเข้าเท่านั้น ห้ามรับสัญลักษณ์แล้วไปหาข้อมูลเอง และห้ามอ่านเวลาปัจจุบัน | ชั้นคำนวณ | P0 |
| BR-ENG-14 | เมื่อสินทรัพย์ในพอร์ตมีช่วงข้อมูลไม่เท่ากัน ให้ใช้ช่วงที่ทุกตัวมีข้อมูลร่วมกัน และรายงานช่วงที่ใช้จริงออกมาด้วย | ชั้นคำนวณ | P0 |
| BR-ENG-15 | ค่าที่คำนวณไม่ได้ตามนิยาม (เช่น Sortino เมื่อไม่มีเดือนที่ติดลบเลย) ต้องรายงานว่าไม่มีค่า ไม่ใช่รายงานเป็นศูนย์ | ชั้นคำนวณ | P0 |
| BR-ENG-16 | ชั้นคำนวณผลิตข้อมูลช่วงขาดทุนครบชุดสำหรับหน้าจอ: (ก) **ซีรีส์รายเดือน**ของสัดส่วนที่ต่ำกว่าจุดสูงสุดเดิม (0 เมื่ออยู่ที่จุดสูงสุด) (ข) **รายการช่วงขาดทุนทุกช่วง** — ช่วงเริ่มเมื่อมูลค่าต่ำกว่าจุดสูงสุดเดิมครั้งแรก จบเมื่อเดือนแรกที่กลับมา ≥ จุดสูงสุดเดิม (หรือระบุว่ายังไม่จบตาม BR-ENG-08) เรียงตามความลึกจากมากไปน้อย ความลึกเท่ากันให้ช่วงที่เกิดก่อนมาก่อน — ช่วงที่ลึกที่สุดต้องตรงกับ BR-ENG-07 | ชั้นคำนวณ | P0 |
