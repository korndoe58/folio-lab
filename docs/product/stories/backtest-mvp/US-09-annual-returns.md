## หมายเหตุ UX

**หน้าจอ/ส่วน:** ส่วนผลตอบแทนรายปี ถัดจากกราฟเส้นมูลค่าที่ `/backtest`

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่เคยทดสอบ | ไม่แสดงส่วนนี้ |
| กำลังโหลด (Loading) | กำลังคำนวณ | โครงร่างของส่วนนี้ |
| ผิดพลาด (Error) | การทดสอบไม่สำเร็จ | ไม่แสดงส่วนนี้ |
| สำเร็จ (Success) | คำนวณเสร็จ | ภาพแท่งรายปีและตารางรายปี |
| สำเร็จบางส่วน (Partial) | มีปีไม่เต็มอยู่ในช่วง | แสดงครบทุกปี โดยปีไม่เต็มมีเครื่องหมายและคำอธิบายกำกับ |

**การโต้ตอบสำคัญ:**
- ชี้หรือโฟกัสที่ปีใดปีหนึ่งเพื่อดูค่าของทั้งพอร์ตและตัวเทียบ

**การเข้าถึง (WCAG AA):** ภาพมีคำอธิบายว่าแสดงอะไร · ตารางรายปีคือข้อมูลเทียบเท่าที่โปรแกรมอ่านหน้าจอใช้ได้ตาม BR-MVP-06 · ปีบวกกับปีลบสื่อด้วยข้อความและทิศทาง ไม่ใช่สีอย่างเดียว · เครื่องหมายปีไม่เต็มอ่านได้ด้วยข้อความ

**Responsive:** จอกว้างแสดงทุกปีในภาพเดียว · จอแคบภาพเลื่อนแนวนอนในกรอบตัวเองหรือลดป้ายกำกับ โดยหน้าเว็บไม่เลื่อนตาม · ตารางเลื่อนในกรอบตัวเอง

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ไม่มี

**คำเตือนการลงทุน:** ใช้ข้อความเดียวกับส่วนผลลัพธ์ตาม BR-MVP-02
