# US-05: ตั้งค่าพอร์ตที่จะทดสอบ

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ⚪ Draft → 🟡 In Review → 🟢 Ready → 🔨 In Dev → ✅ Done
**Priority:** P0 · **Session:** S4 · **Roadmap:** [Phase 1 · feature 1.1](../../../ROADMAP.md) · **Route:** `/backtest` · **Data mode:** จำลอง

> **ในฐานะ** นักลงทุนที่จัดพอร์ตเอง **ฉันต้องการ** ใส่สินทรัพย์กับสัดส่วนที่คิดไว้ได้ง่ายและรู้ทันทีเมื่อกรอกผิด **เพื่อที่จะ** ไปถึงผลลัพธ์โดยไม่ต้องเดาว่าฟอร์มต้องการอะไร

**หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน · P3 เร็วพอที่จะลองซ้ำหลายรอบ

## หมายเหตุ UX

**หน้าจอ/ส่วน:** ฟอร์มตั้งค่าพอร์ตที่ `/backtest` ส่วนบนของหน้า

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | เปิดหน้าครั้งแรกไม่มีค่าในลิงก์ | ฟอร์มเปล่า 2 แถว พร้อมค่าเริ่มต้นของเงินตั้งต้นและตัวเทียบ และทางลัดไปพอร์ตตัวอย่าง |
| กำลังโหลด (Loading) | กำลังตรวจว่าสัญลักษณ์มีข้อมูลไหม | สัญญาณกำลังตรวจในแถวนั้น ช่องอื่นยังกรอกต่อได้ |
| ผิดพลาด (Error) | มีช่องที่ไม่ผ่านการตรวจ | ข้อความใต้ช่องที่ผิด และข้อความน้ำหนักรวมเหนือปุ่ม |
| สำเร็จ (Success) | ทุกช่องผ่านและกดเริ่มทดสอบ | ปุ่มแสดงสถานะกำลังทำงาน แล้วผลลัพธ์ปรากฏด้านล่าง |
| สำเร็จบางส่วน (Partial) | บางสัญลักษณ์ตรวจไม่ได้เพราะติดต่อแหล่งข้อมูลไม่ได้ | ช่องที่ตรวจได้แสดงผลปกติ ช่องที่ตรวจไม่ได้แสดงว่ายังตรวจไม่ได้ และยังกดเริ่มทดสอบได้ |

**การโต้ตอบสำคัญ:**
- เพิ่มหรือลบแถวสินทรัพย์ได้ตลอด และปุ่มลบถูกปิดเมื่อเหลือแถวเดียว
- ออกจากช่องแล้วตรวจทันที ไม่ต้องรอกดส่ง
- กดเฉลี่ยน้ำหนักเท่ากันเพื่อแก้ปัญหาน้ำหนักไม่ครบ 100 ในคลิกเดียว

**การเข้าถึง (WCAG AA):** ทุกช่องมีป้ายกำกับที่อ่านได้ด้วยโปรแกรมอ่านหน้าจอ · ช่องที่บังคับมีเครื่องหมายกำกับ · ข้อความผิดพลาดถูกผูกกับช่องของมันและถูกประกาศเมื่อปรากฏ · เดินด้วยแป้นพิมพ์ได้ครบทุกปุ่มรวมถึงเพิ่มและลบแถว · สื่อความผิดพลาดด้วยข้อความ ไม่ใช่สีอย่างเดียว

**Responsive:** จอกว้าง แถวสินทรัพย์เรียงเป็นคอลัมน์เดียวกันในบรรทัดเดียว · จอแคบ แต่ละแถวซ้อนเป็นบล็อกที่มีป้ายกำกับของตัวเอง ไม่มีการเลื่อนแนวนอนของทั้งหน้า

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ในโหมดข้อมูลจำลอง รายการสัญลักษณ์ที่ตรวจว่ามีจริงจำกัดอยู่ที่ชุดใน BR-CCH-09 เท่านั้น สัญลักษณ์จริงอื่น ๆ จะถูกตอบว่าไม่พบ ซึ่งเป็นข้อจำกัดของข้อมูลจำลอง ไม่ใช่พฤติกรรมที่ผู้ใช้จะเจอในโหมดข้อมูลจริง (สลับที่ S8)

**คำเตือนการลงทุน:** หน้านี้แสดงคำเตือนตาม BR-MVP-02 ที่ท้ายหน้า แม้ยังไม่มีผลลัพธ์

- **Guards:** lint · tsc · vitest · build

- [ ] AC ทุกข้อทดสอบได้ตามที่เขียน
- [ ] ข้อมูล/fixture ที่ต้องใช้ระบุครบ
- [ ] แผนตรวจสอบเขียนแล้ว
- [ ] Dependency เคลียร์ (US-01, US-03 ให้ชั้นข้อมูลและข้อมูลจำลอง)
