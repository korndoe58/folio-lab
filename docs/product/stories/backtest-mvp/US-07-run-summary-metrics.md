## หมายเหตุ UX

**หน้าจอ/ส่วน:** ส่วนผลลัพธ์ด้านล่างฟอร์มที่ `/backtest`

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่เคยกดเริ่มทดสอบ | ข้อความชวนให้กรอกพอร์ตแล้วกดเริ่มทดสอบ พร้อมทางลัดไปพอร์ตตัวอย่าง |
| กำลังโหลด (Loading) | กำลังดึงข้อมูลและคำนวณ | โครงร่างของตารางสรุปตาม BR-SUM-09 |
| ผิดพลาด (Error) | โหลดไม่สำเร็จหรือช่วงเวลาไม่ทับกัน | แถบข้อความอธิบายปัญหา พร้อมทางแก้ที่กดได้ |
| สำเร็จ (Success) | คำนวณเสร็จ | ตารางสรุปสองคอลัมน์ พร้อมช่วงเวลาที่ใช้จริงและคำเตือน |
| สำเร็จบางส่วน (Partial) | ช่วงที่ใช้ได้สั้นกว่าที่ขอ | ผลลัพธ์ครบ พร้อมข้อความ `N-001` อธิบายว่าเหตุใดช่วงจึงสั้นลง |

**การโต้ตอบสำคัญ:**
- เปิดคำอธิบายของแต่ละค่าได้ทั้งด้วยเมาส์และแป้นพิมพ์
- ปุ่มลองใหม่เมื่อโหลดไม่สำเร็จ ทำงานโดยไม่ต้องกรอกฟอร์มใหม่

**การเข้าถึง (WCAG AA):** ตารางมีหัวข้อของแถวและคอลัมน์ที่โปรแกรมอ่านหน้าจอเข้าถึงได้ · การปรากฏของผลลัพธ์ถูกประกาศ · การเปรียบเทียบกับตัวเทียบสื่อด้วยข้อความไม่ใช่สีอย่างเดียวตาม BR-SUM-07 · คำอธิบายศัพท์เข้าถึงด้วยแป้นพิมพ์ได้

**Responsive:** จอกว้างแสดงตารางเต็ม · จอแคบตารางเลื่อนแนวนอนในกรอบของตัวเองโดยหน้าเว็บไม่เลื่อนตาม และหัวข้อแถวยังมองเห็นได้

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ค่าที่แสดงในโหมดข้อมูลจำลองมาจากชุดข้อมูลตรึง จึงเท่าเดิมทุกครั้ง ส่วนความช้าจริงของการดึงข้อมูลและกรณีที่แหล่งข้อมูลล่มกลางทาง จะพบได้เมื่อสลับเป็นข้อมูลจริงใน S8 เท่านั้น

**คำเตือนการลงทุน:** แสดงตาม BR-MVP-02 ท้ายส่วนผลลัพธ์
