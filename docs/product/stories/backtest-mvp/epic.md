# Epic: ทดสอบพอร์ตย้อนหลังและดูผล (backtest-mvp)

**Status:** ⚪ Draft → 🟡 In Review → 🟢 Ready → 🔨 In Dev → ✅ Done
**Roadmap:** [Phase 1 — features 1.1–1.6](../../../ROADMAP.md) · **Session:** S1 author · S4–S8 implement

> **อ่านก่อน (TL;DR)**
> - จอแรกที่ผู้ใช้ได้ใช้จริง: ตั้งพอร์ต กดรัน แล้วเห็นว่าถ้าลงทุนแบบนี้ตั้งแต่ปีนั้นจะเป็นอย่างไร
> - ตอบสามคำถามหลัก: ได้เท่าไร เสี่ยงแค่ไหน แพ้หรือชนะตลาด
> - ทุกอย่างที่ตั้งค่าอยู่ในลิงก์ ส่งต่อให้คนอื่นเปิดแล้วเห็นเหมือนกัน
> - จบ epic นี้คือจุดที่โครงการมีของให้คนอื่นดูได้ครบในตัว
> - ไม่มีระบบสมาชิก ไม่มีการเก็บข้อมูลส่วนตัวใด ๆ

## §1 ปัญหา (Problem)

คนที่จัดพอร์ตเองอยากรู้ว่าส่วนผสมที่คิดไว้เคยให้ผลอย่างไรในอดีต แต่เครื่องมือที่มีอยู่บังคับให้เลือกระหว่าง
ทำเองในตารางคำนวณ (ผิดง่าย โดยเฉพาะเรื่องปันผลและการปรับสมดุล) กับใช้เครื่องมือต่างประเทศที่ตัวเลข
ถูกต้องแต่อ่านไม่ออกถ้าไม่ได้เรียนสายการเงินมา และไม่รองรับสินทรัพย์ไทย

## §2 ผู้ใช้ (Persona)

นักลงทุนรายย่อยที่จัดพอร์ตเอง ลงทุนผ่านกองทุนและ ETF รู้จักคำว่าผลตอบแทนและความเสี่ยงในระดับทั่วไป
แต่ไม่คุ้นกับศัพท์เฉพาะอย่าง Sharpe หรือ drawdown มาก่อน ใช้งานทั้งจากคอมพิวเตอร์และมือถือ

## §3 คุณค่า & ตัววัดความสำเร็จ (Value & Success Metric)

- **คุณค่า:** ตอบคำถาม "ถ้าลงทุนแบบนี้มาตั้งแต่ปีนั้น วันนี้จะเป็นอย่างไร" ได้ในไม่กี่วินาที พร้อมคำอธิบายภาษาไทยที่คนทั่วไปอ่านรู้เรื่อง
- **ตัววัด (วัดได้):**
  1. ตั้งพอร์ตสองสินทรัพย์แล้วเห็นผลครบทุกส่วนภายใน 5 วินาทีบนเครื่องที่ให้บริการจริง
  2. ตัวเลขบนหน้าจอตรงกับที่ชุดทดสอบของ [US-04](../foundation/US-04-engine-core-golden.md) ยืนยันไว้
  3. ลิงก์ที่ก๊อปไปเปิดใหม่ให้ผลเหมือนเดิมทุกครั้ง
  4. ใช้งานได้จริงบนจอกว้าง 375 จุด โดยหน้าเว็บไม่เลื่อนแนวนอน
- **หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน (หลัก) · P1 เลขเชื่อถือได้ · P4 แชร์และทำซ้ำผลได้

## §4 ขอบเขต (Scope)

**อยู่ในขอบเขต:**
- ตั้งพอร์ตหนึ่งชุด (หลายสินทรัพย์) เทียบกับตัวเทียบหนึ่งตัว
- ผลลัพธ์: ตารางสรุป, เส้นมูลค่า, ผลตอบแทนรายปี, ช่วงขาดทุน
- เก็บค่าที่ตั้งไว้ในลิงก์ และพอร์ตตัวอย่างสำหรับเริ่มต้นเร็ว
- คำอธิบายภาษาไทยของทุกค่า และคำเตือนการลงทุนทุกหน้าผล

**นอกขอบเขต (ตั้งใจตัด):**
- เทียบหลายพอร์ตพร้อมกัน, เงินเข้า-ออกระหว่างทาง, ตัวเลือกการปรับสมดุลแบบอื่น (เฟส 2 — เฟสนี้ปรับสมดุลรายปีอย่างเดียว)
- สินทรัพย์ไทยและสกุลเงินอื่น (เฟส 3 — เฟสนี้เป็นสินทรัพย์สหรัฐและสกุลดอลลาร์)
- ค่าความเสี่ยงชุดลึกและช่วงวิกฤต (เฟส 4)
- ระบบสมาชิกและการบันทึกพอร์ตไว้บนเครื่องแม่ข่าย (ไม่มีในแผนเลย ดู §9)
- ดาวน์โหลดผลเป็นไฟล์ (เฟส 2)

## §6 ลำดับการทำงาน (Flow)

1. ผู้ใช้เข้า `/` เลือกพอร์ตตัวอย่าง หรือกดไปตั้งเอง
2. ที่ `/backtest` กรอกสินทรัพย์ น้ำหนัก เงินตั้งต้น ช่วงเวลา และตัวเทียบ
3. กดเริ่มทดสอบ → ค่าที่ตั้งถูกเขียนลงลิงก์ → ระบบขอข้อมูลผ่านชั้นข้อมูล → ส่งให้ชั้นคำนวณ
4. แสดงผลสี่ส่วน: ตารางสรุป, เส้นมูลค่า, ผลตอบแทนรายปี, ช่วงขาดทุน
5. แก้ค่าแล้วกดใหม่ได้เรื่อย ๆ ลิงก์เปลี่ยนตาม
6. เปิดลิงก์เดิมภายหลัง (หรือคนอื่นเปิด) ได้ผลเหมือนเดิม

## §9 กฎร่วมของ epic (Shared Rules)

| ID | กฎ |
| --- | --- |
| BR-MVP-01 | **ไม่มีระบบสมาชิก** ค่าที่ผู้ใช้ตั้งอยู่ในลิงก์เท่านั้น ไม่มีการเก็บข้อมูลผู้ใช้ไว้ที่เครื่องแม่ข่าย และไม่มีกฎเรื่องสิทธิ์การเข้าถึงในการ์ดใด |
| BR-MVP-02 | ทุกหน้าที่แสดงผลการทดสอบต้องมีข้อความ `ผลตอบแทนในอดีตไม่ได้รับประกันผลตอบแทนในอนาคต ข้อมูลในเว็บนี้ไม่ใช่คำแนะนำการลงทุน` |
| BR-MVP-03 | ศัพท์การเงินทุกคำที่ปรากฏบนจอ (ผลตอบแทนต่อปีแบบทบต้น, ความผันผวน, ช่วงขาดทุนสูงสุด, Sharpe, Sortino) ต้องมีคำอธิบายภาษาไทยสั้น ๆ กำกับให้เปิดดูได้ ณ จุดที่ปรากฏ |
| BR-MVP-04 | รูปแบบตัวเลข: เปอร์เซ็นต์แสดงทศนิยม 2 ตำแหน่ง จำนวนเงินแสดงเป็นจำนวนเต็มพร้อมคั่นหลักพัน ค่าที่คำนวณไม่ได้แสดงเป็นขีด ไม่ใช่ 0 |
| BR-MVP-05 | ตัวเทียบเริ่มต้นคือ SPY และเปลี่ยนได้ ทุกส่วนของผลลัพธ์แสดงพอร์ตคู่กับตัวเทียบเสมอ |
| BR-MVP-06 | ทุกกราฟต้องมีข้อมูลรูปแบบตารางหรือข้อความที่เทียบเท่ากันให้โปรแกรมอ่านหน้าจอเข้าถึงได้ |
| BR-MVP-07 | ช่วงเวลาที่ผู้ใช้เลือกระบุเป็นปี ระบบตีความเป็นตั้งแต่เดือนแรกของปีเริ่มต้น ถึงเดือนสุดท้ายของปีสิ้นสุดที่มีข้อมูลครบ |
| BR-MVP-08 | ผลลัพธ์ต้องแสดงช่วงเวลาที่ใช้คำนวณจริงเสมอ เพราะอาจสั้นกว่าที่ผู้ใช้ขอตาม BR-ENG-14 |
