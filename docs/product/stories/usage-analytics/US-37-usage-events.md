## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- เว็บขึ้น production แล้วและเฟส 4 ปิดครบ · **ยังไม่มีเครื่องมือวัดใด ๆ เลยตั้งแต่ S1**

- ชุดทดสอบ e2e รันสองร้อยกว่าข้อทุกครั้งบนโหมดข้อมูลจำลอง — ถ้าปนเข้าไปตัวเลขจะใช้ไม่ได้เลย

## หมายเหตุ UX (อ่านง่าย — ไม่ใช่ component wiring)

**หน้าจอ/ส่วน:** ไม่มีส่วนใหม่บนหน้าจอเลย — งานนี้มองไม่เห็นด้วยตาทั้งหมด

```
┌──────────────────────────────────────────────┐
│  หน้าเว็บเหมือนเดิมทุกพิกเซล                  │
│                                              │
│  [เริ่มทดสอบ]  ──กดแล้วสำเร็จ──▶ run_backtest │
│  [คัดลอกลิงก์] ──คัดลอกสำเร็จ──▶ copy_link    │
│  [บันทึกไฟล์]  ──บันทึกสำเร็จ──▶ download_csv │
│                                              │
│  กดแล้วล้มเหลว ───────────────▶ ไม่ยิงอะไร    │
└──────────────────────────────────────────────┘
```

**5 สถานะ UI:**
| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร (ภาษาคน) |
| --- | --- | --- |
| ว่าง (Empty) | N/A — ไม่มีส่วนแสดงผล | — |
| กำลังโหลด (Loading) | N/A — ไม่ขวางการแสดงผล | — |
| ผิดพลาด (Error) | สคริปต์โหลดไม่ได้ | ไม่เห็นอะไร เว็บทำงานปกติ |
| สำเร็จ (Success) | ทุกกรณีปกติ | ไม่เห็นอะไร — ตั้งใจให้มองไม่เห็น |
| สำเร็จบางส่วน (Partial) | ผู้ใช้บล็อกสคริปต์บุคคลที่สาม | ไม่เห็นอะไร · ฝั่งเราได้ตัวเลขต่ำกว่าจริง |

**การโต้ตอบสำคัญ:** ไม่มีตัวควบคุมใหม่ · ปุ่มเดิมทุกปุ่มต้องทำงานเหมือนเดิมเป๊ะ
**การเข้าถึง (WCAG AA):** ไม่กระทบ — ไม่เพิ่มอะไรใน DOM ที่โปรแกรมอ่านหน้าจอต้องอ่าน
**Responsive:** ไม่กระทบ layout
**ข้อจำกัดข้อมูลจำลอง (stub limitation):** โหมดข้อมูลจำลอง**ปิดการส่งทั้งหมดโดยตั้งใจ** — จึงยืนยัน
ปลายทางจริงด้วยชุดทดสอบไม่ได้ ต้องเดินบนรุ่นที่ build แล้วพร้อมรหัสจริงเท่านั้น
**คำเตือนการลงทุน:** ไม่กระทบ — หน้าผลลัพธ์ยังแสดงคำเตือนเดิมครบตาม R12

## แผนตรวจสอบ (Verification Plan)

- **Unit:** ตัวห่อยิงชื่อเหตุการณ์และพารามิเตอร์ถูก · **ไม่ยิงเมื่อไม่มีรหัส** · **ไม่ยิงในโหมดข้อมูลจำลอง**
  · ใช้ตัวส่งปลอมที่ฉีดเข้าไป ไม่ต่อเน็ต (BR-USE-18)
- **E2E:** ข้อใหม่ที่ดักคำขอทั้งหน้าแล้วยืนยันว่า**ไม่มีคำขอออกไปหาบริการวัดผลเลย** (AC-USE-04)
- **บน route (ต้องเป็นรุ่นที่ build แล้ว):**
  - ตั้งรหัสจริง → เดิน `/backtest?…` → ดักคำขอ อ่านชื่อเหตุการณ์และพารามิเตอร์ (AC-USE-01, 02, 07)
  - **อ่านเนื้อคำขอทุกอันเทียบกับเงินและหุ้นที่กรอกไว้** (AC-USE-03) — ข้อนี้ตรวจด้วยตาไม่พอ ต้องเทียบสตริง
  - ถอดรหัสออก → ยืนยันว่าเว็บยังครบและเงียบสนิท (AC-USE-05)
- **ฝั่ง PO:** ยืนยันว่าเหตุการณ์ปรากฏจริงในหน้าจอเรียลไทม์ของบริการวัดผล — เข้าบัญชีแทนกันไม่ได้
- **Guards:** lint · tsc · vitest · **build** (แตะ layout = แตะ routing) · E2E · golden เขียวโดยไม่ถูกแตะ

### ✏️ แก้ไขคำอ้างของหลักฐาน (เพิ่มภายหลัง ไม่ลบของเดิม)

ตารางข้างบนเขียนว่าเหตุการณ์ **"ยิงถึงจริง"** ซึ่ง**อ้างเกินกว่าที่พิสูจน์ได้** ·
สิ่งที่หลักฐานชุดนั้นพิสูจน์คือ **คำขอออกจากเบราว์เซอร์ครบถ้วนและถูกต้อง** เท่านั้น

**เหตุ:** บริการวัดผล**กรองทราฟฟิกจากบอทออกอัตโนมัติและปิดไม่ได้** · การเดินหน้าอัตโนมัติ
ส่ง user agent ที่ถูกจัดเป็นบอท คำขอจึงถูกรับแล้วทิ้ง · **ปลายทางตอบ `204` เหมือนกันทั้งกรณี
เก็บและไม่เก็บ** จึงแยกสองกรณีนี้จากฝั่งเบราว์เซอร์ไม่ได้เลย

**ยืนยันปลายทางได้จริงเมื่อ PO เปิดเว็บด้วยเบราว์เซอร์ของตัวเองแล้วข้อมูลขึ้นในรายงานเรียลไทม์ทันที**
— นั่นคือหลักฐานชิ้นเดียวที่พิสูจน์ข้อนี้ได้ และไม่มีเครื่องมืออัตโนมัติตัวไหนทดแทนได้
