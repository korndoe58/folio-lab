## หมายเหตุ UX (อ่านง่าย — ไม่ใช่ component wiring)

**หน้าจอ/ส่วน:** ไม่มีอะไรเปลี่ยนบนหน้าจอเลย — เหมือน US-37 คืองานนี้มองไม่เห็นด้วยตาทั้งหมด

```

│  ผู้ใช้จาก EU/UK/สวิส  ──▶ ปฏิเสธทุกข้อ ไม่มีคุกกี้   │
│                            ข้อมูลไม่ถูกนับ           │
│                                                    │
│  ผู้ใช้ที่อื่น          ──▶ อนุญาตเฉพาะการวัดผล      │
│                            โฆษณายังปฏิเสธ           │
│                                                    │
│  หน้าเว็บที่ทั้งสองกลุ่มเห็น เหมือนกันทุกพิกเซล        │
└────────────────────────────────────────────────────┘
```

**5 สถานะ UI:** ไม่มีส่วนแสดงผล — ยกมาจาก US-37 ทั้งตาราง ไม่มีอะไรเปลี่ยน
**การโต้ตอบสำคัญ:** ไม่มีตัวควบคุมใหม่
**การเข้าถึง (WCAG AA):** ไม่กระทบ
**Responsive:** ไม่กระทบ
**ข้อจำกัดข้อมูลจำลอง (stub limitation):** โหมดข้อมูลจำลองปิดการส่งทั้งหมด จึงยืนยันด้วยชุดทดสอบไม่ได้
**ข้อจำกัดที่ใหญ่กว่านั้น:** **ยืนยันฝั่งเขตที่ปฏิเสธด้วยเครื่องในไทยไม่ได้** เพราะปลายทางตัดสิน
เขตจากที่อยู่เครือข่ายของผู้ใช้ · สิ่งที่ยืนยันได้คือ **คำสั่งที่เราส่งออกไปถูกต้องและครบ**
ส่วนปลายทางจะบังคับใช้ตามนั้นหรือไม่ อยู่นอกการควบคุมของเรา — ห้ามอ้างว่าตรวจฝั่งยุโรปแล้ว
**คำเตือนการลงทุน:** ไม่กระทบ
