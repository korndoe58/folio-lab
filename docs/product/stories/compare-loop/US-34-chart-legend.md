## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- BR-CMP-28 ตั้งใจให้แยกพอร์ตด้วย**ลายเส้นและความทึบ ไม่พึ่งสี** ซึ่งถูกต้องแล้ว
  (พิมพ์ขาวดำได้ · คนแยกสีไม่ออกก็อ่านได้) — แต่**ไม่เคยมีใครเพิ่มป้ายที่บอกว่าลายไหนคือใคร**
- ชื่อพอร์ตถูกส่งเข้ากราฟผ่าน `name=` ของทุกเส้นอยู่แล้ว โปรแกรมกราฟเอาไปใช้เฉพาะ
  ในกล่องที่โผล่ตอนเอาเมาส์ชี้ — **บนมือถือไม่มีเมาส์จึงไม่มีทางรู้**
- การ์ดนี้จึงเป็นการเติมของที่ขาดไป ไม่ใช่การเปลี่ยนวิธีแยกเส้น · `series-style.ts` คงเดิมทุกค่า

## หมายเหตุ UX

**หน้าจอ/ส่วน:** ใต้พื้นที่วาดของกราฟทั้งสี่ ภายในกรอบการ์ดเดิม

**ก่อน** (เทียบสามพอร์ต — เดาไม่ออกว่าเส้นไหนของใคร):
```
┌────────────────────────────────────────┐
│ เส้นมูลค่าพอร์ต            [สเกลปกติ]  │
│                                        │
│      ╱╲    ╱╲╱                         │
│   ╱╲╱  ╲╱╲╱     ← เส้นสีเดียวกันหมด    │
│ ╱                 ต่างแค่ลาย            │
│                                        │
│ ▸ ดูเป็นตาราง                          │
└────────────────────────────────────────┘
```

**หลัง**:
```
┌────────────────────────────────────────┐
│ เส้นมูลค่าพอร์ต            [สเกลปกติ]  │
│                                        │
│      ╱╲    ╱╲╱                         │
│   ╱╲╱  ╲╱╲╱                            │
│ ╱                                      │
│                                        │
│  ──────  พอร์ต 1                       │  ← ป้ายใหม่
│  ─ ─ ─   พอร์ต 2                       │     ตัวอย่างลายวาดด้วย
│  ·· ··   พอร์ต 3                       │     ค่าเดียวกับในกราฟ
│  ·  ·    เงินที่ใส่สะสมของพอร์ต 2       │     (จาง)
│  ─ ─     ตลาด (SPY)                    │     (จาง)
```

**กราฟแบบแท่ง (รายปี · หน้าต่างเลื่อน)** ใช้ตัวอย่างเป็นแท่งทึบต่างระดับแทนลายเส้น:
```
  ███   พอร์ต 1
  ▓▓▓   พอร์ต 2
  ░░░   พอร์ต 3
```

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่เคยรัน | ไม่มีกราฟ จึงไม่มีป้าย |
| กำลังโหลด (Loading) | กำลังคำนวณ | ยังไม่มีป้าย โผล่พร้อมกราฟ |
| ผิดพลาด (Error) | รันไม่สำเร็จ | ไม่มีกราฟ จึงไม่มีป้าย |
| สำเร็จ (Success) | มีผลแล้ว | ป้ายครบทุกชุดข้อมูลที่วาดอยู่ในกราฟนั้น |
| สำเร็จบางส่วน (Partial) | บางกราฟไม่ถูกวาด (เช่นไม่มีช่วงขาดทุน) | ป้ายมีเฉพาะกราฟที่ถูกวาดจริง (EC-LOOP-02) |

**การโต้ตอบสำคัญ:** ไม่มี — ป้ายอ่านอย่างเดียว **กดไม่ได้** · การกดป้ายเพื่อซ่อนเส้น
อยู่นอกขอบเขตของ epic นี้

**การเข้าถึง (WCAG AA):** ป้ายเป็นรายการจริง (`role="list"`) · ชื่ออยู่ในข้อความ ไม่ใช่ในภาพ ·
ตัวอย่างลายมี `aria-hidden` เพราะเป็นภาพประกอบซ้ำความหมายที่ข้อความบอกอยู่แล้ว (BR-LOOP-08) ·
ความหมายไม่ได้อยู่ที่สีอย่างเดียวตาม BR-CMP-28 เดิม

**Responsive:** ป้ายไหลขึ้นบรรทัดใหม่เมื่อจอแคบ · ตัวอย่างลายกับชื่ออยู่แถวเดียวกันเสมอ
ไม่แยกจากกันตอนตัดบรรทัด

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ไม่มี — ป้ายไม่ใช้ข้อมูลจากภายนอกเลย

**คำเตือนการลงทุน:** ข้อความเดิมตาม BR-MVP-02 ไม่เปลี่ยน

## แผนตรวจสอบ (Verification Plan)

- **Guards:** lint · tsc · vitest · build · e2e ทั้ง repo (ต้องเขียวครบเท่าเดิมก่อนและหลัง)
