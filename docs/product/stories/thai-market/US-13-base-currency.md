# US-13: เลือกสกุลเงินฐานของพอร์ต

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** 🟢 Ready (S9) · เส้นทาง: ⚪ → 🟡 → **🟢 Ready** → 🔨 In Dev → ✅ Done
**Priority:** P0 · **Session:** S11 · **Roadmap:** [Phase 3 · feature 3.3](../../../ROADMAP.md) · **Route:** `/backtest` · **Data mode:** จริง

> **ในฐานะ** นักลงทุนไทยที่วางแผนการเงินเป็นเงินบาท **ฉันต้องการ** เลือกได้ว่าจะดูผลเป็นเงินบาทหรือดอลลาร์ **เพื่อที่จะ** อ่านตัวเลขในหน่วยที่ฉันใช้ตัดสินใจจริง

**หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน · P1 เลขเชื่อถือได้

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- [US-12](./US-12-currency-conversion.md) ทำให้ชั้นข้อมูลแปลงผลตอบแทนตามสกุลเงินฐานที่ได้รับได้แล้ว
- story นี้คือส่วนที่ผู้ใช้มองเห็นและควบคุม: ช่องเลือกสกุลเงิน ค่าในลิงก์ และหน่วยเงินบนจอ
- กฎเดิม BR-MVP-04 ที่บังคับให้ทุกจำนวนเงินเป็นดอลลาร์ ถูกแทนที่ด้วย BR-THB-10

## กฎทางธุรกิจ (Business Rules)

| Rule ID | กฎ | เจ้าของค่า | Priority |
| --- | --- | --- | --- |
| BR-CUR-01 | ฟอร์มมีช่องเลือกสกุลเงินฐาน สองตัวเลือกคือเงินบาทและดอลลาร์สหรัฐ ค่าเริ่มต้นคือเงินบาท (BR-THB-02) | หน้าจอ | P0 |
| BR-CUR-02 | สกุลเงินฐานเป็นส่วนหนึ่งของค่าที่เก็บในลิงก์ เหมือนช่องอื่นทุกช่อง | หน้าจอ | P0 |
| BR-CUR-03 | ลิงก์เก่าที่ไม่ระบุสกุลเงินฐาน ต้องยังเปิดได้และให้ผลเหมือนเดิม — ถือว่าเป็นฐานดอลลาร์ เพราะลิงก์ที่แชร์ไปก่อนหน้านี้ทั้งหมดเป็นดอลลาร์ | หน้าจอ | P0 |
| BR-CUR-04 | จำนวนเงินทุกจุดบนจอแสดงหน่วยของสกุลเงินฐาน (`฿` หรือ `$`) — ตารางสรุป กราฟ ตารางประกอบ ช่องเงินตั้งต้น และแกนของกราฟ | หน้าจอ | P0 |
| BR-CUR-05 | เมื่อพอร์ตมีสินทรัพย์คนละสกุลกับสกุลเงินฐาน ต้องบอกผู้ใช้ว่าตัวเลขถูกแปลงค่าเงินแล้ว ด้วยข้อความ `N-002` (BR-THB-07) | หน้าจอ | P0 |
| BR-CUR-06 | เปลี่ยนสกุลเงินฐานแล้วต้องรันใหม่จึงจะเห็นผลใหม่ เหมือนการแก้ช่องอื่น ๆ — ไม่คำนวณใหม่เองระหว่างพิมพ์ | หน้าจอ | P1 |
| BR-CUR-07 | ค่าเงินตั้งต้นเป็นจำนวนในสกุลเงินฐาน ไม่ถูกแปลงเมื่อสลับสกุลเงิน (10,000 ยังคงเป็น 10,000 แต่เปลี่ยนหน่วย) | หน้าจอ | P0 |
| BR-CUR-08 | คำอธิบายของช่องเลือกสกุลเงินบอกให้เข้าใจว่าการเลือกนี้มีผลอย่างไร โดยไม่ใช้ศัพท์เทคนิค | หน้าจอ | P1 |
| BR-CUR-09 | หน้าจอไม่แปลงค่าเงินเอง ทำได้แค่ส่งสกุลเงินฐานไปให้ชั้นข้อมูลและแสดงหน่วยตามที่เลือก (BR-THB-03) | หน้าจอ | P0 |

## หมายเหตุ UX

**หน้าจอ/ส่วน:** ช่องเลือกสกุลเงินในฟอร์มที่ `/backtest` และหน่วยเงินในทุกส่วนของผลลัพธ์

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่เคยรัน | ช่องสกุลเงินมีค่าเริ่มต้นเป็นเงินบาท |
| กำลังโหลด (Loading) | กำลังคำนวณ | ช่องสกุลเงินยังอ่านได้แต่เปลี่ยนไม่ได้ระหว่างรอ |
| ผิดพลาด (Error) | แปลงค่าเงินไม่ได้ | แถบข้อความพร้อมทางแก้ |
| สำเร็จ (Success) | คำนวณเสร็จ | ผลลัพธ์ในหน่วยของสกุลเงินฐาน + ข้อความแจ้งเมื่อมีการแปลง |
| สำเร็จบางส่วน (Partial) | ช่วงถูกย่อเพราะอัตราแลกเปลี่ยน | ผลลัพธ์ครบพร้อม `N-001` |

**การโต้ตอบสำคัญ:** เลือกสกุลเงิน → กดเริ่มทดสอบ → ทุกหน่วยและตัวเลขเปลี่ยนพร้อมกัน

**การเข้าถึง (WCAG AA):** ช่องเลือกมีป้ายกำกับที่โปรแกรมอ่านหน้าจอเข้าถึงได้ · เปลี่ยนค่าด้วยแป้นพิมพ์ได้ ·
ข้อความแจ้งการแปลงค่าเงินไม่พึ่งสีอย่างเดียว

**Responsive:** ช่องสกุลเงินอยู่แถวเดียวกับเงินตั้งต้นบนจอกว้าง และขึ้นบรรทัดใหม่บนจอแคบ

**ข้อจำกัดที่ต้องบอก:** รองรับสองสกุลเงิน คำอธิบายของช่องระบุว่าระบบดูสกุลเงินของสินทรัพย์
จากรูปแบบสัญลักษณ์

**คำเตือนการลงทุน:** ใช้ข้อความเดิมตาม BR-MVP-02

## แผนตรวจสอบ (Verification Plan)

- **ชุดทดสอบ:** การอ่าน-เขียนค่าสกุลเงินในลิงก์ รวมกรณีลิงก์เก่าไม่มีค่านี้ (ต้องได้ดอลลาร์) · การเลือก
  หน่วยเงินตามสกุล · ค่าที่ไม่รู้จักในลิงก์ต้องกลายเป็น `V-008`
- **บน route:** `/backtest` — เลือกเงินบาทแล้วรัน VTI 100 ดูว่าหน่วยเป็นบาทและมีข้อความแจ้งการแปลง ·
  สลับเป็นดอลลาร์แล้วรันใหม่ ตรวจว่าค่าและหน่วยเปลี่ยนครบทุกจุดรวมแกนกราฟ · เปิดลิงก์เก่าจากหลักฐาน
  ของ S8 แล้วยืนยันว่าได้ค่าเดิมเป๊ะ · เดินด้วยแป้นพิมพ์ · จอ 375 จุด · ทั้งสองธีม
- **Guards:** lint · tsc · vitest · build
