# Epic: ลงทุนข้ามตลาดไทยและต่างประเทศในพอร์ตเดียว (thai-market)

**Status:** 🟢 Ready (S9) · เส้นทาง: ⚪ → 🟡 → **🟢 Ready** → 🔨 In Dev → ✅ Done
**Roadmap:** [Phase 3 — features 3.2, 3.3](../../../ROADMAP.md) · **Session:** S9 author · S10–S11 implement
**ลำดับ:** ยกมาก่อนเฟส 2 ตาม [PD-011](../../decision-log.md)

> **อ่านก่อน (TL;DR)**
> - นักลงทุนไทยถือทั้งหุ้นไทยและกองทุนต่างประเทศ แต่เครื่องมือที่มีบังคับให้เลือกอย่างใดอย่างหนึ่ง
> - epic นี้ทำให้พอร์ตผสมสองสกุลเงินคำนวณได้**ถูกต้อง** โดยเลือกได้ว่าจะมองผลเป็นเงินบาทหรือดอลลาร์
> - หุ้นไทยใช้ได้อยู่แล้วในทางเทคนิค แต่ยังไม่มีใครรู้ และตัวเลขยังผิดเมื่อผสมสกุลเงิน — รอบนี้แก้ทั้งสองอย่าง
> - กองทุนรวมไทยกับการปรับเงินเฟ้อ **ไม่อยู่ใน epic นี้** เพราะยังไม่รู้ว่าแหล่งข้อมูลมีลึกพอไหม (รอ spike ที่ S12)

---

## §1 ปัญหา (Problem)

คนไทยที่จัดพอร์ตเองมักถือของสองโลกพร้อมกัน — หุ้นไทยหรือกองทุนไทยส่วนหนึ่ง กับกองทุนต่างประเทศ
อีกส่วนหนึ่ง แต่เครื่องมือ backtest ที่มีอยู่รองรับแค่สินทรัพย์ต่างประเทศ พอจะดูภาพรวมทั้งพอร์ตจึงต้อง
ทำเองในตารางคำนวณ ซึ่งจุดที่ผิดบ่อยที่สุดคือ**ลืมว่าผลตอบแทนของสินทรัพย์ต่างประเทศเมื่อมองเป็นเงินบาท
รวมส่วนต่างค่าเงินอยู่ด้วย**

ปัญหานี้มีอยู่ในเครื่องมือของเราเองแล้วด้วย: หุ้นไทยใส่ได้ตั้งแต่ตอนนี้ (เติม `.BK` ท้ายสัญลักษณ์)
แต่ระบบเอาผลตอบแทนสกุลบาทมาบวกกับสกุลดอลลาร์ตรง ๆ — ตัวเลขที่ได้จึงไม่ตรงกับสิ่งที่ผู้ถือจริงได้รับ

## §2 ผู้ใช้ (Persona)

นักลงทุนรายย่อยชาวไทยที่มีทั้งพอร์ตหุ้นไทยและพอร์ตกองทุนต่างประเทศ คิดเป็นเงินบาทเป็นหลักเพราะ
ใช้จ่ายและวางแผนเกษียณเป็นเงินบาท แต่บางคนอยากดูเป็นดอลลาร์เพื่อเทียบกับข้อมูลต่างประเทศที่อ่านมา

## §3 คุณค่า & ตัววัดความสำเร็จ (Value & Success Metric)

- **คุณค่า:** ตอบคำถาม "ถ้าถือหุ้นไทยครึ่งหนึ่งกับกองทุนต่างประเทศครึ่งหนึ่ง ผลจริงเป็นอย่างไรเมื่อคิดเป็นเงินบาท"
  ซึ่งไม่มีเครื่องมือฟรีเจ้าไหนตอบได้
- **ตัววัด (วัดได้):**
  1. พอร์ตผสม (หุ้นไทย 50% + กองทุนต่างประเทศ 50%) ให้ผลที่ตรวจทานกับการคำนวณมือได้ ทั้งฐานบาทและฐานดอลลาร์
  2. พอร์ตที่มีสินทรัพย์สกุลเดียวให้ผลเท่าเดิมทุกตัวเลขกับก่อนมี epic นี้ (ไม่ทำของเดิมพัง)
  3. ผู้ใช้ที่เปิดเว็บครั้งแรกรู้ได้เองว่าใส่หุ้นไทยได้ โดยไม่ต้องมีใครบอก
  4. ไม่มีเส้นทางไหนที่ทำให้ได้ตัวเลขผสมสกุลเงินโดยไม่แปลงค่า
- **หลักที่ยึด:** P1 เลขเชื่อถือได้ (หลัก) · P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## §4 ขอบเขต (Scope)

**อยู่ในขอบเขต:**
- รู้ว่าสินทรัพย์แต่ละตัวซื้อขายด้วยสกุลเงินอะไร
- ดึงอัตราแลกเปลี่ยนบาทต่อดอลลาร์รายเดือน และแปลงผลตอบแทนให้เป็นสกุลเงินฐานเดียวกัน
- ให้ผู้ใช้เลือกสกุลเงินฐานของพอร์ต (บาทหรือดอลลาร์) และแสดงหน่วยเงินตามที่เลือกทุกจุด
- หุ้นไทยในรายการแนะนำ + พอร์ตตัวอย่างที่มีหุ้นไทย

**นอกขอบเขต (ตั้งใจตัด):**
- **กองทุนรวมไทย** — ต้องต่อแหล่งข้อมูลใหม่ที่ยังไม่รู้ความลึก รอ spike ที่ S12 (feature 3.1)
- **การปรับเงินเฟ้อ** — ต้องหาแหล่งดัชนีราคาผู้บริโภคไทยก่อน รอ spike เดียวกัน (feature 3.4)
- สกุลเงินอื่นนอกจากบาทและดอลลาร์ (ยูโร เยน) — เพิ่มได้ภายหลังด้วยรูปแบบเดียวกัน
- ภาษีและค่าธรรมเนียมการซื้อขาย (ไม่มีในแผนทั้งโครงการ)
- การป้องกันความเสี่ยงค่าเงิน (hedged share class) — เป็นเรื่องของการเลือกสินทรัพย์ ไม่ใช่ของเครื่องมือ

## §6 ลำดับการทำงาน (Flow)

1. ผู้ใช้ใส่สินทรัพย์ที่มีทั้งหุ้นไทยและกองทุนต่างประเทศ แล้วเลือกสกุลเงินฐาน (ค่าเริ่มต้นตาม §9)
2. ชั้นข้อมูลดึงผลตอบแทนของแต่ละสินทรัพย์ตามปกติ **พร้อมกับ**อัตราแลกเปลี่ยนรายเดือนช่วงเดียวกัน
3. สินทรัพย์ที่สกุลเงินไม่ตรงกับสกุลเงินฐาน ถูกแปลงผลตอบแทนก่อนส่งต่อ
4. ชั้นคำนวณทำงานเหมือนเดิมทุกประการ เพราะได้รับชุดผลตอบแทนที่เป็นสกุลเดียวกันหมดแล้ว
5. หน้าจอแสดงผลพร้อมหน่วยเงินของสกุลเงินฐาน และบอกให้รู้ว่ามีการแปลงค่าเงินเกิดขึ้น

## §9 กฎร่วมของ epic (Shared Rules)

| ID | กฎ |
| --- | --- |
| BR-THB-01 | **สกุลเงินของสินทรัพย์อ่านจากรูปแบบสัญลักษณ์** — ลงท้าย `.BK` = เงินบาท · นอกนั้นถือเป็นดอลลาร์สหรัฐ กติกานี้เป็นความรู้ของชั้นข้อมูล ไม่ใช่ของผู้ใช้ |
| BR-THB-02 | **สกุลเงินฐานเริ่มต้นคือเงินบาท** เพราะผู้ใช้เป้าหมายวางแผนการเงินเป็นเงินบาท และเปลี่ยนเป็นดอลลาร์ได้ |
| BR-THB-03 | การแปลงเกิดที่ชั้นข้อมูลก่อนเข้าชั้นคำนวณ — ชั้นคำนวณและหน้าจอไม่แปลงค่าเงินเอง (ต่อยอด R15) |
| BR-THB-04 | ผลตอบแทนเดือนหนึ่งเมื่อมองจากสกุลเงินฐาน = (1 + ผลตอบแทนสกุลเดิม) × (1 + การเปลี่ยนแปลงของอัตราแลกเปลี่ยนเดือนนั้น) − 1 |
| BR-THB-05 | อัตราแลกเปลี่ยนใช้หน่วยเดียวกับผลตอบแทนคือ**รายเดือน ณ สิ้นเดือน** และผ่านกติกาเดียวกับราคาทุกข้อ (เดือนที่ปิดแล้วเท่านั้น · อัตราส่วนจากชุดที่ดึงรอบเดียวกัน) |
| BR-THB-06 | พอร์ตที่ทุกสินทรัพย์เป็นสกุลเดียวกับสกุลเงินฐาน **ต้องไม่ถูกแตะเลย** — ไม่ดึงอัตราแลกเปลี่ยน ไม่แปลงค่า ผลลัพธ์เท่าเดิมทุกหลัก |
| BR-THB-07 | เมื่อมีการแปลงค่าเงินเกิดขึ้น ต้องบอกผู้ใช้ให้รู้ พร้อมระบุว่าตัวเลขที่เห็นเป็นสกุลอะไร |
| BR-THB-08 | ตัวเทียบก็ถูกแปลงเป็นสกุลเงินฐานเช่นกัน มิฉะนั้นเป็นการเทียบคนละหน่วย |
| BR-THB-09 | ถ้าดึงอัตราแลกเปลี่ยนไม่สำเร็จ **ห้ามแสดงผลที่ยังไม่แปลงค่า** ให้แจ้งข้อผิดพลาดแทน — ตัวเลขที่ผิดแย่กว่าไม่มีตัวเลข |
| BR-THB-10 | หน่วยเงินบนจอเป็นของสกุลเงินฐาน (บาทใช้ `฿` · ดอลลาร์ใช้ `$`) ทุกจุดที่แสดงจำนวนเงิน แทนที่กฎเดิมที่บังคับดอลลาร์เสมอ |
