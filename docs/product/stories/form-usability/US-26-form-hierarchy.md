# US-26: ลำดับชั้นของฟอร์มที่มองเห็นได้

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S16c) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P1 · **Session:** S16c · **Route:** `/backtest` · **Data mode:** จริง

> **ในฐานะ** คนที่เปิดฟอร์มครั้งแรก **ฉันต้องการ** เห็นว่าอะไรเป็นค่าของพอร์ตและอะไรเป็นค่าของการทดสอบ **เพื่อที่จะ** รู้ว่าเปลี่ยนช่องไหนแล้วกระทบอะไร โดยไม่ต้องเดา

**หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- [PD-014](../../decision-log.md) แบ่งไว้ชัดตั้งแต่ S14 ว่าค่าไหนเป็นของพอร์ตและค่าไหนใช้ร่วมกัน
  แต่**เส้นแบ่งนั้นมองไม่เห็นบนจอ**ในโหมดพอร์ตเดียว
- โหมดหลายพอร์ตมีกรอบต่อพอร์ตและหัวข้อ `ค่าที่ใช้ร่วมกันทุกพอร์ต` อยู่แล้วตั้งแต่ S15 —
  ของที่ต้องแก้คือโหมดพอร์ตเดียวซึ่งเป็นโหมดที่คนเจอก่อน
- คำว่า "ทุกพอร์ต" ในโหมดพอร์ตเดียวอ่านแปลก จึงต้องใช้คำต่างกันตามโหมด

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | เปิดหน้าครั้งแรก | สองกรอบพร้อมหัวข้อ |
| กำลังโหลด (Loading) | กำลังคำนวณ | ฟอร์มเหมือนเดิม ปุ่มเปลี่ยนข้อความ |
| ผิดพลาด (Error) | มีข้อความตรวจสอบ | ข้อความอยู่ในกรอบของส่วนที่ผิด |
| สำเร็จ (Success) | คำนวณเสร็จ | ฟอร์มเหมือนเดิม ผลอยู่ด้านล่าง |
| สำเร็จบางส่วน (Partial) | ไม่มีกรณีเฉพาะของการ์ดนี้ | — |

**การโต้ตอบสำคัญ:** ไม่เปลี่ยน — ทุกช่องอยู่ที่เดิมและทำงานเหมือนเดิม เปลี่ยนแค่ขอบเขตที่มองเห็น

**การเข้าถึง (WCAG AA):** ใช้ `fieldset` กับ `legend` ที่มีอยู่แล้ว โปรแกรมอ่านหน้าจอจึงประกาศ
ชื่อกลุ่มก่อนอ่านช่องในกลุ่ม · ไม่พึ่งกรอบหรือสีอย่างเดียวในการสื่อขอบเขต

**Responsive:** กรอบและระยะห่างย่อตามจอแคบ · หน้าไม่เลื่อนแนวนอน

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ไม่มี
