# US-27: ข้อความตรวจสอบหายเมื่อแก้ถูก

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S16c) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P0 · **Session:** S16c · **Route:** `/backtest` · **Data mode:** จริง

> **ในฐานะ** คนที่กดรันแล้วเจอข้อความสีแดง **ฉันต้องการ** ให้ข้อความหายไปทันทีที่ฉันแก้ถูก **เพื่อที่จะ** รู้ว่าแก้ผ่านแล้วโดยไม่ต้องกดรันเพื่อถามระบบ

**หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- ผลการตรวจถูกคำนวณเฉพาะตอนกดเริ่มทดสอบ และตอนออกจากช่องสัญลักษณ์เพื่อถามแหล่งข้อมูล
- แก้ค่าจนถูกแล้วข้อความยังค้าง เพราะไม่มีใครสั่งให้ตรวจใหม่
- ตรวจใหม่ทุกครั้งที่พิมพ์ก็ไม่ได้ เพราะจะขึ้นข้อความใส่หน้าคนที่ยังพิมพ์ไม่จบ
  (พิมพ์ `60` จะโดนเตือนตอนพิมพ์ `6` เสร็จ · ลบค่าเพื่อพิมพ์ใหม่ก็ผ่านสถานะว่างเสมอ)
- [PD-018](../../decision-log.md) ตัดสินแล้วว่าให้**แยกจังหวะลบออกจากจังหวะเพิ่ม**

## หมายเหตุ UX

**หน้าจอ/ส่วน:** ข้อความตรวจสอบทุกจุดในฟอร์มที่ `/backtest`

```
สถานะ            ก่อน                        หลัง
กรอกฟอร์มแรก     เงียบ ✓                     เงียบ ✓
กดรัน + มีผิด     แดงขึ้น ✓                   แดงขึ้น ✓
แก้ค่าจนถูก       แดงค้างจนกดรันใหม่ ✗        แดงหายทันที ✓
พิมพ์ "6"→"60"    (แดงเดิมค้างอยู่แล้ว)        ไม่มีแดงใหม่ระหว่างพิมพ์ ✓
กดรันอีกครั้ง     ตรวจใหม่ทั้งหมด ✓           ตรวจใหม่ทั้งหมด ✓
```

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่กดรัน | ไม่มีข้อความใด ๆ |
| กำลังโหลด (Loading) | กำลังคำนวณ | ข้อความชุดเดิมยังอยู่จนผลใหม่มา |
| ผิดพลาด (Error) | กดรันแล้วมีช่องผิด | ข้อความใต้ช่องที่ผิด |
| สำเร็จ (Success) | แก้ถูกแล้ว | ข้อความหายทีละช่องตามที่แก้ |
| สำเร็จบางส่วน (Partial) | แก้ถูกบางช่อง | ช่องที่แก้แล้วหาย ช่องที่เหลือยังอยู่ |

**การโต้ตอบสำคัญ:** แก้ถูก → หายทันที · พิมพ์ค้างครึ่งทาง → เงียบ · กดรัน → ตรวจใหม่ทั้งหมด

**การเข้าถึง (WCAG AA):** ข้อความยังใช้ `role="alert"` และผูกกับช่องผ่าน `aria-describedby`
เหมือนเดิม · ข้อความที่หายไปไม่ทิ้งพื้นที่ว่างที่ทำให้ฟอร์มกระโดด

**Responsive:** ไม่เปลี่ยน

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ไม่มี

**คำเตือนการลงทุน:** ข้อความเดิมตาม BR-MVP-02
