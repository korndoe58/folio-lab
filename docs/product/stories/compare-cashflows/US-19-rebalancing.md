# US-19: เลือกวิธีปรับสมดุลพอร์ต

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S15b) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P1 · **Session:** S15b · **Roadmap:** [Phase 2 · feature 2.3](../../../ROADMAP.md) · **Route:** `/backtest?<ค่าที่ตั้ง>` · **Data mode:** จริง

> **ในฐานะ** คนที่ลังเลว่าการดึงน้ำหนักพอร์ตกลับที่เดิมทุกปีคุ้มกับความยุ่งยากไหม **ฉันต้องการ** เทียบพอร์ตเดียวกันด้วยวิธีปรับสมดุลที่ต่างกัน **เพื่อที่จะ** ตัดสินด้วยตัวเลขแทนความรู้สึก

**หลักที่ยึด:** P1 เลขเชื่อถือได้ · P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- ชั้นคำนวณดึงน้ำหนักกลับสู่เป้าหมาย ณ สิ้นเดือนธันวาคมอยู่แล้ว และรองรับตัวเลือก "ไม่ปรับ" อยู่แล้ว
  ตั้งแต่ US-04 — การ์ดนี้เพิ่มความถี่ที่เหลือและแบบที่ปรับตามการเบี่ยงเบน ไม่ได้เขียนกลไกใหม่
- **ค่าเริ่มต้นต้องเป็นรายปีต่อไป** เพราะทุกผลลัพธ์ที่ ship ไปแล้วและทุกลิงก์ที่แชร์ไปแล้วคำนวณด้วยค่านี้
- วิธีปรับสมดุลตั้งแยกรายพอร์ตตามตารางเจ้าของค่าใน [`epic.md`](./epic.md) §9 — ถ้าเป็นค่าร่วม
  จะตอบคำถามของการ์ดนี้ไม่ได้เลย

| BR-CMP-59 | **ผู้ใช้เลือกวิธีกระจายเงินที่ใส่เพิ่มเองต่อพอร์ต** ([PD-016](../../decision-log.md)) — **ตามสัดส่วนที่ถืออยู่** (ค่าปริยาย · ทุกตัวถูกคูณเท่ากัน น้ำหนักไม่ขยับ ชุดผลตอบแทนจึงไม่ถูกแตะ) หรือ **ตามน้ำหนักเป้าหมาย** (เป็นการดึงน้ำหนักกลับเข้าเป้าไปในตัว ชุดผลตอบแทนจึงเปลี่ยนได้ ซึ่งถูกต้องตามนิยามของวิธีนี้) · การใส่เงินไม่ถูกนับเป็นครั้งของการปรับสมดุลตามรอบไม่ว่าเลือกแบบไหน | ชั้นคำนวณ | P0 |

| BR-CMP-61 | พอร์ตที่มีสินทรัพย์เดียว ทุกวิธีให้ผลเท่ากันเพราะไม่มีอะไรให้ปรับ | ชั้นคำนวณ | P2 |
| BR-CMP-62 | ลิงก์เก็บวิธีปรับสมดุลไว้ในพารามิเตอร์ของพอร์ตนั้น พร้อมเกณฑ์เมื่อเป็นแบบเบี่ยงเบน | หน้าจอ | P0 |
| BR-CMP-63 | ตารางสรุปมีแถวบอก **จำนวนครั้งที่ปรับสมดุล** ตลอดช่วง เพื่อให้ผู้ใช้เห็นว่าวิธีที่เลือกต้องลงมือกี่ครั้งจริง ๆ ไม่ใช่เห็นแค่ผลตอบแทน | ชั้นคำนวณ | P1 |

## Edge Cases (อย่างน้อย 3)

| # | สถานการณ์ | พฤติกรรมที่คาดหวัง |
| --- | --- | --- |
| EC-CMP-18 | ตั้งแบบเบี่ยงเบนเกณฑ์ 50 จุดบนพอร์ตที่น้ำหนักแทบไม่ขยับ | ไม่มีการปรับเลยตลอดช่วง จำนวนครั้งเป็น 0 และผลเท่ากับการตั้งไม่ปรับ |

| EC-CMP-22 | เปลี่ยนวิธีปรับสมดุลแล้วเปลี่ยนกลับ | ได้ค่าเดิมทุกหลัก ไม่สะสมความคลาดเคลื่อน |

**การโต้ตอบสำคัญ:** เลือกแบบเบี่ยงเบน → ช่องเกณฑ์ปรากฏพร้อมค่าเริ่มต้น 5 และคำอธิบายที่แปลงเกณฑ์
เป็นช่วงน้ำหนักจริงให้เห็น · เปลี่ยนวิธี → ผลเดิมยังอยู่จนกว่าจะกดรันใหม่

**การเข้าถึง (WCAG AA):** ตัวเลือกและช่องเกณฑ์เข้าถึงด้วยแป้นพิมพ์ได้ · ช่องเกณฑ์ที่ปรากฏเพิ่มถูก
ประกาศให้โปรแกรมอ่านหน้าจอรู้ · คำอธิบายที่แปลงเกณฑ์เป็นช่วงน้ำหนักผูกกับช่องนั้น

**Responsive:** ตัวเลือกและช่องเกณฑ์เรียงลงมาบนจอแคบ

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ไม่มี — การ์ดนี้ทำงานบนชุดผลตอบแทนที่มีอยู่แล้ว

**คำเตือนการลงทุน:** ข้อความเดิมตาม BR-MVP-02 · เพิ่มหมายเหตุว่าไม่คิดค่าธรรมเนียมและภาษี
