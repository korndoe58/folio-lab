# US-17: ดูกราฟและตารางทุกส่วนของหลายพอร์ตพร้อมกัน

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S15) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P0 · **Session:** S15 · **Roadmap:** [Phase 2 · feature 2.1](../../../ROADMAP.md) · **Route:** `/backtest?<ค่าที่ตั้ง>` · **Data mode:** จริง

> **ในฐานะ** คนที่เพิ่งเทียบค่าสรุปของสองพอร์ตแล้วเห็นว่าต่างกัน **ฉันต้องการ** เห็นกราฟและตารางที่เหลือซ้อนกันด้วย **เพื่อที่จะ** รู้ว่าความต่างนั้นมาจากช่วงไหนและเจ็บตอนไหน ไม่ใช่รู้แค่ว่าตัวเลขสุดท้ายต่างกัน

**หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- US-16 ทำให้ตั้งได้ถึง 3 พอร์ตและตารางสรุปแสดงครบแล้ว การ์ดนี้ทำส่วนที่เหลือของหน้าผลลัพธ์
- **การ์ดนี้คือการกวาดตามกฎ R13 ที่ใหญ่ที่สุดของโครงการ** — ทุกส่วนที่สร้างตั้งแต่ S6 ถึง S13
  เป็นผู้รับผลกระทบ จึงไล่ชื่อไว้เป็นรายการข้างล่างแทนที่จะเขียนรวม ๆ ว่า "ทุกส่วนรองรับหลายพอร์ต"
- สิ่งที่ต้องไม่หายไประหว่างทาง: หน่วยสกุลเงินตามฐานที่เลือก (US-13) · คำกำกับ "หักเงินเฟ้อแล้ว"
  และข้อความที่กราฟมูลค่า (US-15) · ตารางเทียบเท่าสำหรับโปรแกรมอ่านหน้าจอของทุกกราฟ (US-08, US-09)
