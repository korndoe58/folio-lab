# US-22: คัดลอกลิงก์ผลลัพธ์ไปแชร์

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** 🟢 Ready (S14) · เส้นทาง: ⚪ → 🟡 → **🟢 Ready** → 🔨 In Dev → ✅ Done
**Priority:** P2 · **Session:** S16 · **Roadmap:** [Phase 2 · feature 2.6](../../../ROADMAP.md) · **Route:** `/backtest?<ค่าที่ตั้ง>` · **Data mode:** จริง

> **ในฐานะ** คนที่เพิ่งได้ผลเทียบที่อยากให้เพื่อนดู **ฉันต้องการ** คัดลอกลิงก์ได้ด้วยการกดครั้งเดียว **เพื่อที่จะ** ส่งต่อได้โดยไม่ต้องลากเลือกที่อยู่ยาว ๆ แล้วเสี่ยงคัดลอกไม่ครบ

**หลักที่ยึด:** P4 แชร์/ทำซ้ำผลได้

---

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- ค่าที่ตั้งทั้งหมดอยู่ในลิงก์อยู่แล้วตั้งแต่ US-06 และทุกการ์ดของ epic นี้ต่อยอดกติกาเดิม —
  การ์ดนี้จึงไม่ได้ทำให้ลิงก์ "แชร์ได้" แต่ทำให้ **แชร์ได้จริงโดยไม่พลาด**
- ลิงก์ยาวขึ้นมากเมื่อมี 3 พอร์ตพร้อมเงินเข้าออกและวิธีปรับสมดุล การลากเลือกจากแถบที่อยู่จึงเสี่ยง
  คัดลอกไม่ครบ ซึ่งจะทำให้ตัววัดข้อ 3 ของ epic ล้มทั้งที่ระบบทำถูก
- การ์ดนี้เป็นด่านสุดท้ายที่ยืนยันว่า **ทุกค่าที่ epic นี้เพิ่มเข้ามาเดินทางไปกลับผ่านลิงก์ได้ครบ**

## หมายเหตุ UX

**หน้าจอ/ส่วน:** ปุ่มคัดลอกลิงก์ที่หัวส่วนผลลัพธ์ที่ `/backtest`

```
สรุปผลการทดสอบ                                    [คัดลอกลิงก์]
มกราคม 2012 ถึง มิถุนายน 2026 · 174 เดือน

           ↓ หลังกด
สรุปผลการทดสอบ                              [✓ คัดลอกแล้ว]      ← หายเองใน ~2 วินาที

           ↓ ถ้าเบราว์เซอร์ไม่อนุญาต
┌──────────────────────────────────────────────────────────┐
│ คัดลอกลิงก์นี้ด้วยตัวเอง                                 │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ https://…/backtest?p1=VTI:60,BND:40&p1.n=ผสม&…      │ │  ← เลือกได้ทั้งหมด
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่เคยรัน | ไม่มีปุ่ม |
| กำลังโหลด (Loading) | กำลังคำนวณ | ไม่มีปุ่มจนกว่าผลจะพร้อม |
| ผิดพลาด (Error) | คัดลอกไม่สำเร็จ | ลิงก์เป็นข้อความที่เลือกได้พร้อมคำแนะนำ |
| สำเร็จ (Success) | คัดลอกสำเร็จ | การตอบกลับว่าคัดลอกแล้ว หายไปเอง |
| สำเร็จบางส่วน (Partial) | ไม่มี — ทำงานครั้งเดียวจบ | — |

**การโต้ตอบสำคัญ:** กดปุ่ม → คัดลอกทันทีพร้อมการตอบกลับ · การตอบกลับหายเองโดยไม่ต้องกดปิด ·
ลิงก์ที่ได้คือของผลที่แสดงอยู่ ไม่ใช่ของค่าที่กำลังแก้ในฟอร์ม

**การเข้าถึง (WCAG AA):** ปุ่มโฟกัสและกดด้วยแป้นพิมพ์ได้ · การตอบกลับถูกประกาศให้โปรแกรมอ่าน
หน้าจอรู้ ไม่ใช่แค่เปลี่ยนสีปุ่ม · กล่องลิงก์สำรองโฟกัสได้และเลือกทั้งหมดได้ด้วยแป้นพิมพ์

**Responsive:** ปุ่มขึ้นบรรทัดใหม่ใต้หัวข้อบนจอแคบ · กล่องลิงก์สำรองตัดบรรทัดโดยไม่ทำให้หน้าเลื่อนแนวนอน

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ไม่มี
