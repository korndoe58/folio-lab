# US-18: ใส่เงินเพิ่มหรือถอนออกระหว่างทาง

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S15b) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P0 · **Session:** S15b · **Roadmap:** [Phase 2 · feature 2.2](../../../ROADMAP.md) · **Route:** `/backtest?<ค่าที่ตั้ง>` · **Data mode:** จริง

> **ในฐานะ** คนที่ทยอยลงทุนทุกเดือนไม่ใช่ลงทีเดียว **ฉันต้องการ** จำลองการใส่เงินเพิ่ม (หรือถอนออก) ระหว่างทาง **เพื่อที่จะ** เห็นผลของวิธีที่ฉันทำจริง ไม่ใช่ผลของวิธีที่ฉันไม่เคยทำ

**หลักที่ยึด:** P1 เลขเชื่อถือได้ (หลัก) · P2 เข้าใจได้โดยไม่ต้องจบการเงิน

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- เครื่องมือวันนี้สมมติว่าใส่เงินก้อนเดียวตอนต้นแล้วไม่แตะอีกเลย ซึ่งไม่ใช่พฤติกรรมของคนส่วนใหญ่
- US-16 ทำให้ตั้งหลายพอร์ตได้แล้ว การ์ดนี้ทำให้เทียบ "ลงทีเดียว" กับ "ทยอยลงทุน" ด้วยสินทรัพย์
  ชุดเดียวกันได้ ซึ่งเป็นคำถามที่คนถามบ่อยที่สุดข้อหนึ่ง
- **เมื่อมีเงินเข้าออก คำว่า "ผลตอบแทนต่อปี" มีสองความหมายที่ต่างกันจริง** — ค่าหนึ่งวัดฝีมือของพอร์ต
  อีกค่าวัดว่าเงินของผู้ใช้โตกี่เปอร์เซ็นต์ต่อปี ทั้งสองถูกคนละแบบ และการแสดงค่าเดียวโดยไม่บอกว่าเป็น
  ค่าไหนคือความเสียหายที่ร้ายแรงที่สุดของเฟสนี้ ([PD-015](../../decision-log.md))
- ดัชนีเงินเฟ้อไทยรายปีที่ freeze ไว้แล้วจาก US-15 ใช้ต่อได้ทันทีสำหรับงวดที่ปรับตามเงินเฟ้อ

## กฎทางธุรกิจ (Business Rules)

| Rule ID | กฎ | เจ้าของค่า | Priority |
| --- | --- | --- | --- |
| BR-CMP-33 | เงินเข้าออกตั้งได้**รายพอร์ต** · ค่าเริ่มต้นคือไม่มีเงินเข้าออก ซึ่งให้ผลเท่าเดิมทุกหลักกับก่อนมีการ์ดนี้ | หน้าจอ | P0 |
| BR-CMP-34 | หนึ่งพอร์ตมีทิศทางเดียว: **ใส่เพิ่ม** หรือ **ถอนออก** — ไม่ผสมกันในพอร์ตเดียว เพราะการผสมทำให้อ่านผลไม่ออกและตอบคำถามที่ผู้ใช้ถามจริงไม่ได้เพิ่ม | หน้าจอ | P1 |
| BR-CMP-35 | ความถี่เลือกได้: **รายเดือน · รายไตรมาส · รายปี** | หน้าจอ | P0 |
| BR-CMP-36 | จำนวนต่องวดระบุได้สองแบบ: **จำนวนเงินคงที่** หรือ **เปอร์เซ็นต์ของมูลค่าพอร์ต ณ งวดนั้น** (แบบเปอร์เซ็นต์ใช้ได้เฉพาะตอนถอน) | หน้าจอ | P1 |
| BR-CMP-37 | **งวดเกิดที่สิ้นเดือน หลังผลตอบแทนของเดือนนั้นถูกคิดแล้ว** — เงินที่ใส่เดือนนี้ยังไม่ได้ผลตอบแทนของเดือนนี้ ลำดับนี้ต้องคงที่เสมอเพราะเป็นตัวกำหนดค่าที่ได้ | ชั้นคำนวณ | P0 |
| BR-CMP-38 | งวดแรกคือสิ้นเดือนแรกของช่วง จากนั้นทุก 1 เดือน (รายเดือน) · 3 เดือน (รายไตรมาส) · 12 เดือน (รายปี) · งวดสุดท้ายไม่เกินเดือนสุดท้ายของช่วง | ชั้นคำนวณ | P0 |
| BR-CMP-39 | เส้นมูลค่าของพอร์ตที่มีเงินเข้าออก = เริ่มที่เงินตั้งต้น แล้วแต่ละเดือนคูณด้วย (1 + ผลตอบแทนเดือนนั้น) แล้วบวกเงินที่ใส่หรือลบเงินที่ถอนของงวดนั้น | ชั้นคำนวณ | P0 |
| BR-CMP-40 | **ชุดผลตอบแทนรายเดือนของพอร์ตไม่ถูกแตะเลย** — ความผันผวน ช่วงขาดทุน Sharpe Sortino ปีดี/แย่ที่สุด และผลตอบแทนต่อปีแบบทบต้น ใช้นิยามเดิมทุกตัว (BR-CMP-10) | ชั้นคำนวณ | P0 |
| BR-CMP-41 | **มูลค่าสุดท้าย**มาจากเส้นมูลค่าตาม BR-CMP-39 ไม่ใช่เงินตั้งต้นคูณผลตอบแทนสะสม (BR-CMP-11) | ชั้นคำนวณ | P0 |
| BR-CMP-42 | เพิ่มแถว **เงินที่ใส่ทั้งหมด** = เงินตั้งต้น + ผลรวมเงินที่ใส่ทุกงวด · พอร์ตที่ตั้งเป็นถอนออก แถวนี้เปลี่ยนเป็น **เงินที่ถอนออกทั้งหมด** = ผลรวมเงินที่ถอนได้จริงทุกงวด | ชั้นคำนวณ | P0 |
| BR-CMP-43 | เพิ่มแถว **ผลตอบแทนต่อปีถ่วงน้ำหนักเงิน** — หาอัตราต่อเดือน `r` ที่ทำให้ผลรวมของกระแสเงินทุกงวดหารด้วย `(1+r)` ยกกำลังจำนวนเดือนนับจากต้นช่วง เท่ากับศูนย์ โดยกระแสเงินคือ: ต้นช่วง `−เงินตั้งต้น` · ทุกงวด `−เงินที่ใส่` หรือ `+เงินที่ถอน` · สิ้นช่วง `+มูลค่าสุดท้าย` แล้วแปลงเป็นรายปีด้วย `(1+r)^12 − 1` | ชั้นคำนวณ | P0 |
| BR-CMP-44 | การหา `r` ต้องให้ผลเท่าเดิมทุกครั้งสำหรับข้อมูลชุดเดิม — ใช้วิธีแบ่งครึ่งช่วงบนช่วงอัตราต่อเดือน `−0.99` ถึง `1.00` จนความคลาดเคลื่อนน้อยกว่า 1e-10 | ชั้นคำนวณ | P0 |
| BR-CMP-45 | **หาค่าไม่ได้ → คืนไม่มีค่า ไม่ใช่ 0** (BR-CMP-14) เมื่อกระแสเงินไม่เปลี่ยนเครื่องหมายเลย หรือหาคำตอบในช่วงที่กำหนดไม่พบ · จอต้องบอกเหตุผลด้วย | ชั้นคำนวณ | P0 |
| BR-CMP-46 | สองแถวใหม่นี้แสดงเฉพาะพอร์ตที่มีเงินเข้าออก · พอร์ตที่ไม่มี ช่องของแถวนั้นเป็นขีด | หน้าจอ | P0 |
| BR-CMP-47 | **ผลตอบแทนต่อปีทั้งสองแบบต้องมีป้ายกำกับที่บอกได้ว่าวัดอะไร พร้อมคำอธิบายไทยที่อธิบายความต่าง** — ห้ามแสดงค่าเดียวเคียงข้างมูลค่าสุดท้ายที่มีเงินเข้าออกโดยไม่ระบุ (BR-CMP-13) | หน้าจอ | P0 |
| BR-CMP-48 | เมื่อไม่มีเงินเข้าออก ผลตอบแทนถ่วงน้ำหนักเงินเท่ากับผลตอบแทนต่อปีแบบทบต้นเสมอ — ใช้ข้อนี้เป็นเทสต์ยืนยันว่าสูตรถูก | ชั้นคำนวณ | P0 |
| BR-CMP-49 | เลือกให้จำนวนเงินต่องวด**เพิ่มตามเงินเฟ้อ**ได้ (เฉพาะแบบจำนวนคงที่) — จำนวนถูกปรับ ณ ต้นปีปฏิทินใหม่ ด้วยอัตราเงินเฟ้อไทยของปีก่อนหน้า ใช้ดัชนีชุดเดียวกับ US-15 · ปีที่ไม่มีดัชนีถือว่าเงินเฟ้อเป็นศูนย์ | ชั้นคำนวณ | P1 |
| BR-CMP-50 | ถอนเกินมูลค่าที่มี ถอนได้เท่าที่มี มูลค่าเป็นศูนย์ และงวดถัด ๆ ไปถอนไม่ได้อีก · แจ้ง `N-004` พร้อมเดือนที่หมด | ชั้นคำนวณ | P0 |
| BR-CMP-51 | ยอดรวมเงินที่จะใส่ทั้งช่วงแสดงในฟอร์มทันทีที่ตั้งค่าเสร็จ ก่อนกดรัน — เพื่อให้ผู้ใช้เห็นว่ากำลังจะเทียบด้วยเงินคนละก้อนกัน | หน้าจอ | P1 |
| BR-CMP-52 | ลิงก์เก็บเงินเข้าออกไว้ในพารามิเตอร์ของพอร์ตนั้น · พารามิเตอร์ที่ไม่มี = ไม่มีเงินเข้าออก ลิงก์เก่าจึงให้ค่าเดิม | หน้าจอ | P0 |
