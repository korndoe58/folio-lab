# US-16: ตั้งค่าและเทียบพอร์ตได้ถึง 3 ชุด

**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S15) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P0 · **Session:** S15 · **Roadmap:** [Phase 2 · feature 2.1](../../../ROADMAP.md) · **Route:** `/backtest?<ค่าที่ตั้ง>` · **Data mode:** จริง

> **ในฐานะ** นักลงทุนที่กำลังชั่งใจระหว่างพอร์ตสองแบบที่ต่างกันนิดเดียว **ฉันต้องการ** ตั้งหลายพอร์ตในการรันเดียวแล้วเห็นค่าสรุปเรียงข้างกัน **เพื่อที่จะ** ตอบได้ว่าอันไหนดีกว่าโดยไม่ต้องเปิดสองแท็บแล้วจำตัวเลขมาเทียบเอง

**หลักที่ยึด:** P2 เข้าใจได้โดยไม่ต้องจบการเงิน · P4 แชร์/ทำซ้ำผลได้

---

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- ฟอร์มพอร์ตเดียวและตารางสรุป 9 แถวใช้งานได้อยู่แล้ว (US-05, US-07) · ค่าที่ตั้งอยู่ในลิงก์ครบแล้ว (US-06)
- สกุลเงินฐาน (US-13) และตัวเลือกปรับเงินเฟ้อ (US-15) เป็นค่าร่วมของการเทียบตามตารางเจ้าของค่าใน
  [`epic.md`](./epic.md) §9 — การ์ดนี้ไม่เปลี่ยนความหมายของทั้งสองค่า แค่ทำให้ใช้ร่วมกันทุกพอร์ต
- ลิงก์ที่แชร์ไปแล้วใช้รูปแบบ `assets=` และมีค่าที่บันทึกเป็นหลักฐานไว้ตั้งแต่ S8 — การ์ดนี้ต้องไม่ทำให้
  ลิงก์เหล่านั้นเปลี่ยนความหมาย

| AC-CMP-02 | ฟอร์มมีพอร์ตเดียว | กดเพิ่มพอร์ตเทียบสองครั้ง | • ได้พอร์ตครบ 3 ชุด ชื่อเริ่มต้น `พอร์ต 1` `พอร์ต 2` `พอร์ต 3`<br>• ปุ่มเพิ่มใช้ไม่ได้แล้วพร้อมบอกเหตุผลว่าเทียบได้สูงสุด 3 พอร์ต |

## Edge Cases (อย่างน้อย 3)

| # | สถานการณ์ | พฤติกรรมที่คาดหวัง |
| --- | --- | --- |
| EC-CMP-01 | เทียบพอร์ตที่มีสินทรัพย์และน้ำหนักเหมือนกันทุกอย่าง | คำนวณตามปกติและได้ค่าเท่ากันทุกแถว ไม่ต้องเตือนอะไร — เป็นวิธีที่ผู้ใช้ใช้ตรวจว่าตัวเองเปลี่ยนอะไรไปบ้าง |
| EC-CMP-02 | ลิงก์มี `p1` ถึง `p4` | ถือว่าอ่านโครงสร้างไม่ออก แจ้ง `V-008` แล้วเติมสามพอร์ตแรกลงฟอร์มให้แก้ต่อได้ |
| EC-CMP-03 | ลิงก์มี `p2` แต่ไม่มี `p1` | อ่านพอร์ตที่มีเป็นพอร์ตแรก ไม่ถือว่าโครงสร้างเสีย เพราะยังตีความได้แบบเดียว |
| EC-CMP-04 | พอร์ตหนึ่งมีสินทรัพย์ที่ไม่มีข้อมูล อีกพอร์ตปกติ | แจ้ง `V-003` ที่ช่องนั้น และยังไม่คำนวณอะไรเลย เพราะช่วงเวลาร่วมยังตัดสินไม่ได้ |
| EC-CMP-05 | ลบพอร์ตกลางออกจากสามพอร์ต | พอร์ตที่เหลือเลื่อนขึ้นและชื่อเริ่มต้นที่ยังไม่ถูกแก้เรียงใหม่ให้ต่อเนื่อง · ชื่อที่ผู้ใช้ตั้งเองไม่ถูกเปลี่ยน |
| EC-CMP-06 | ตั้งชื่อพอร์ตเป็นช่องว่างล้วน | ใช้ชื่อเริ่มต้นของลำดับนั้นแทน ไม่ถือเป็นข้อผิดพลาด |
| EC-CMP-36 | กดเริ่มทดสอบรัว ๆ ขณะที่รอบก่อนหน้ายังคำนวณไม่เสร็จ | ทำงานรอบเดียว และประวัติของหน้าไม่เพิ่มรายการซ้ำ ต่อเนื่องจากพฤติกรรมเดิมของฟอร์มพอร์ตเดียว |
| EC-CMP-37 | รีเฟรชหรือปิดแท็บระหว่างที่กำลังโหลดข้อมูล | เปิดลิงก์เดิมใหม่แล้วรันเองตั้งแต่ต้น ไม่มีสถานะครึ่ง ๆ กลาง ๆ ค้างอยู่ |
| EC-CMP-38 | แก้ค่าแล้วกดรันรอบใหม่ก่อนรอบเก่าจะเสร็จ | ผลของรอบเก่าต้องไม่ทับผลของรอบล่าสุด แม้ข้อมูลของรอบเก่าจะมาถึงทีหลัง |
| EC-CMP-39 | กดย้อนกลับหลังรันการเทียบสองชุดติดกัน | กลับไปที่การเทียบชุดก่อนหน้าครบทุกพอร์ตพร้อมชื่อและผลของชุดนั้น |
| EC-CMP-40 | สลับภาษาไทยกับอังกฤษกลางคันขณะกรอกฟอร์มหลายพอร์ต | ค่าที่กรอกไว้ทุกพอร์ตยังอยู่ครบ รวมทั้งชื่อพอร์ตที่ผู้ใช้ตั้งเอง |
| EC-CMP-41 | สัญลักษณ์เดียวกันปรากฏในสองพอร์ตและยังไม่เคยโหลด | ดึงข้อมูลของสัญลักษณ์นั้นรอบเดียวตาม BR-CMP-06 และทั้งสองพอร์ตได้ค่าชุดเดียวกัน |

**5 สถานะ UI:**

| สถานะ | เกิดเมื่อ | ผู้ใช้เห็นอะไร |
| --- | --- | --- |
| ว่าง (Empty) | ยังไม่เคยรัน | ฟอร์มพอร์ตเดียวพร้อมปุ่มเพิ่มพอร์ตเทียบ |
| กำลังโหลด (Loading) | กำลังคำนวณ | โครงร่างตารางที่มีคอลัมน์เท่าจำนวนพอร์ตที่กำลังรัน |
| ผิดพลาด (Error) | ตรวจไม่ผ่านหรือโหลดข้อมูลไม่ได้ | ข้อความใต้ช่องของพอร์ตที่มีปัญหา หรือแถบแจ้งเมื่อเป็นปัญหาระดับการรัน |
| สำเร็จ (Success) | คำนวณเสร็จ | ตารางสรุปที่มีคอลัมน์ครบทุกพอร์ตและตัวเทียบ |
| สำเร็จบางส่วน (Partial) | ช่วงเวลาถูกย่อตามข้อมูลที่มี | ผลครบพร้อมข้อความ `N-001` |

**การโต้ตอบสำคัญ:** กดเพิ่มพอร์ต → บล็อกใหม่ปรากฏพร้อมโฟกัสที่ช่องสัญลักษณ์แรกของบล็อกนั้น ·
แก้ชื่อพอร์ต → หัวคอลัมน์เปลี่ยนหลังรันรอบถัดไป ไม่ใช่ทันที เพื่อไม่ให้ป้ายไม่ตรงกับตัวเลขที่แสดงอยู่ ·
ลบพอร์ตที่มีผลแสดงอยู่ → ผลเดิมยังอยู่จนกว่าจะรันใหม่

**การเข้าถึง (WCAG AA):** ทุกบล็อกพอร์ตเป็นกลุ่มที่มีชื่อกำกับ โปรแกรมอ่านหน้าจอบอกได้ว่ากำลังอยู่ใน
พอร์ตไหน · ปุ่มลบบอกชื่อพอร์ตที่จะลบ ไม่ใช่แค่คำว่าลบ · หัวคอลัมน์ผูกกับเซลล์ค่าเพื่อให้อ่านทีละเซลล์
แล้วรู้ว่าเป็นค่าของพอร์ตไหน · ข้อความแจ้งข้อผิดพลาดระบุชื่อพอร์ตในตัวข้อความ ไม่พึ่งตำแหน่งบนจอ

**Responsive:** บล็อกพอร์ตเรียงลงมาบนจอแคบ · ตารางสรุปเลื่อนแนวนอนในกรอบของตัวเองโดยคอลัมน์ชื่อแถว
ยังอ่านได้ · หน้าเว็บทั้งหน้าต้องไม่เลื่อนแนวนอน

**ข้อจำกัดข้อมูลจำลอง (stub limitation):** ชุดข้อมูลจำลองไม่จำลองความเร็วที่ต่างกันของแต่ละสัญลักษณ์
การรวมผลจากหลายพอร์ตที่มาถึงคนละจังหวะจึงพิสูจน์ได้เฉพาะกับข้อมูลจริง

**คำเตือนการลงทุน:** หน้าผลลัพธ์แสดงข้อความเดิมตาม BR-MVP-02
