**Epic แม่:** [`./epic.md`](./epic.md) · **Status:** ✅ Done (S16) · เส้นทาง: ⚪ → 🟡 → 🟢 Ready → 🔨 In Dev → **✅ Done**
**Priority:** P2 · **Session:** S16 · **Roadmap:** [Phase 2 · feature 2.5](../../../ROADMAP.md) · **Route:** `/backtest?<ค่าที่ตั้ง>` · **Data mode:** จริง

> **ในฐานะ** คนที่อยากเอาผลไปคำนวณต่อในโปรแกรมตารางคำนวณของตัวเอง **ฉันต้องการ** เห็นตัวเลขรายเดือนดิบ ๆ และบันทึกออกเป็นไฟล์ได้ **เพื่อที่จะ** ทำสิ่งที่เครื่องมือนี้ยังไม่รองรับได้เองโดยไม่ต้องรอ

## บริบท & เงื่อนไขก่อนหน้า (Context & Preconditions)

- ทุกค่าที่แสดงบนจอมาจากชุดผลตอบแทนรายเดือน แต่ผู้ใช้ยังเห็นแค่ผลสรุป ไม่เคยเห็นตัวเลขตั้งต้น
- ส่วนนี้เป็นทางออกที่ตั้งใจให้ power user ทำอะไรต่อเองได้ แทนที่จะไล่เพิ่มความสามารถยิบย่อยเข้ามา
- ต้องครอบคลุมทุกพอร์ตที่กำลังเทียบอยู่ ตาม BR-CMP-25

**การโต้ตอบสำคัญ:** กดหัวข้อ → ตารางกางออกและปุ่มบันทึกไฟล์ยังกดได้แม้ตารางพับอยู่ ·
กดบันทึกไฟล์ → ไฟล์ถูกดาวน์โหลดทันทีโดยไม่ต้องรอโหลดอะไรเพิ่ม เพราะข้อมูลอยู่ในเครื่องแล้ว

**การเข้าถึง (WCAG AA):** หัวข้อที่พับได้เข้าถึงด้วยแป้นพิมพ์และบอกสถานะพับ/กาง ·
ตารางมีหัวแถวเป็นเดือนและหัวคอลัมน์เป็นชื่อพอร์ต ผูกกันเพื่อให้อ่านทีละเซลล์ได้ ·
ปุ่มบันทึกไฟล์บอกได้ว่ากำลังจะได้ไฟล์อะไร ไม่ใช่แค่คำว่าบันทึก

**Responsive:** ตารางเลื่อนแนวนอนในกรอบของตัวเองโดยคอลัมน์เดือนยังอ่านได้ · ปุ่มบันทึกไฟล์
ขึ้นบรรทัดใหม่ใต้หัวข้อบนจอแคบ
