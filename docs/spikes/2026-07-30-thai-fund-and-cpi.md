# Spike: แหล่งข้อมูลกองทุนรวมไทย และดัชนีเงินเฟ้อไทย

**วันที่:** 2026-07-30 · **Session:** S12 · **สถานะ:** ปิดแล้ว → [PD-012](../product/decision-log.md)

> เอกสารนี้เขียนเพิ่มอย่างเดียว ไม่แก้ย้อนหลัง — ถ้าสถานการณ์เปลี่ยน ให้เขียนรายงานฉบับใหม่

## คำถามที่ต้องตอบ

โรดแมประบุว่าสองฟีเจอร์นี้ **ห้ามเขียน spec ก่อน spike** เพราะขอบเขตขึ้นกับข้อมูลจริงล้วน ๆ:

1. **กองทุนรวมไทย (3.1)** — ข้อมูลมูลค่าหน่วยลงทุนย้อนหลังลึกพอไหม เรียกได้อย่างไร มีข้อจำกัดอะไร
2. **ปรับเงินเฟ้อไทย (3.4)** — มีดัชนีราคาผู้บริโภคให้ใช้ไหม ความละเอียดระดับไหน

## 1. กองทุนรวมไทย

| `api.sec.or.th/FundDailyInfo/fund/dailynav/2024-01-31` | HTTP 401 เหมือนกัน | เส้นทางมูลค่าหน่วยลงทุนรายวันมีอยู่จริง |
| `api.sec.or.th` (ราก) | HTTP 404 พร้อม JSON ปกติ | เครื่องให้บริการตอบสนองตามปกติ ไม่ได้ล่ม |
| DNS ของ `api-portal.sec.or.th` · `opendata.sec.or.th` · `data.sec.or.th` | หาไม่เจอทั้งสามโดเมน | พอร์ทัลลงทะเบียนเข้าจากที่นี่ไม่ได้ |
| `www.sec.or.th` | HTTP 403 | น่าจะจำกัดการเข้าถึงจากนอกประเทศ |

**บริบทเพิ่มเติมที่ค้นเจอ:** พอร์ทัลนักพัฒนาเดิมถูกปิดเมื่อ 30 มิถุนายน 2026 และย้ายไปรวมกับ
แพลตฟอร์มข้อมูลเปิดตัวใหม่ตั้งแต่ 12 มกราคม 2026 · การยืนยันตัวตนใช้คีย์ในส่วนหัวของคำขอ

### มีทางเลี่ยงไหม — ตรวจแล้วว่าไม่มี

ค้นกองทุนไทยบนแหล่งข้อมูลที่โปรเจกต์ใช้อยู่แล้ว (ซึ่งมีหุ้นไทยครบ):

| คำค้น | ผลลัพธ์ |
| --- | --- |
| `K-USA` | ไม่พบ |
| `SCB S&P500` | ไม่พบ |
| `Kasikorn fund` | ไม่พบ |
| `One fund` (คำกลาง ๆ) | พบกองทุน 6 รายการ แต่เป็นของตลาดยุโรปทั้งหมด (`.F` แฟรงก์เฟิร์ต · `.L` ลอนดอน) |

สรุป: แหล่งข้อมูลปัจจุบันมี**หุ้น**ไทยครบ แต่**ไม่มีกองทุนรวม**ไทยเลย ต่างจากกรณีหุ้นไทยกับ
อัตราแลกเปลี่ยนที่พบว่าใช้ได้ฟรีตั้งแต่ต้น จึงไม่มีทางลัดแบบเดียวกัน

### ข้อสรุป

**ยังตอบไม่ได้ว่าข้อมูลย้อนหลังลึกพอไหม** เพราะยิงไม่ผ่านด่านคีย์ — และคีย์ต้องสมัครผ่านพอร์ทัล
ที่เข้าจากสภาพแวดล้อมนี้ไม่ได้ ต้องเป็นคนที่เข้าถึงได้จากในประเทศเป็นผู้ดำเนินการ

**เงื่อนไขที่จะทำต่อได้ทันทีโดยไม่ต้อง spike ซ้ำ:** มีคีย์ใช้งานได้หนึ่งอัน เมื่อนั้นคำถามที่เหลือ
(ความลึกย้อนหลัง · ข้อจำกัดการเรียก · การจับคู่ชื่อกองทุน) ตอบได้ภายในครึ่ง session
เพราะสถาปัตยกรรมรองรับการเพิ่มแหล่งข้อมูลใหม่โดยไม่แตะชั้นคำนวณอยู่แล้ว
