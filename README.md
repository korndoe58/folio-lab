# folio-lab

เครื่องมือทดสอบพอร์ตลงทุนย้อนหลัง (backtest) ที่ตอบคำถามเดียว: **ถ้าลงทุนแบบนี้มาตั้งแต่ปีนั้น วันนี้จะเป็นอย่างไร**

**ลองใช้เลย →** <https://folio-lab-gamma.vercel.app>

```
พอร์ตอ้างอิง VTI 48% · VNQ 8% · VXUS 24% · BND 20% (ม.ค. 2012 – มิ.ย. 2026)
เงินตั้งต้น $10,000  →  $41,495   ผลตอบแทนต่อปี 10.31%   ช่วงขาดทุนสูงสุด −23.55% (ฟื้นใน 1 ปี 6 เดือน)
```

---

## ปัญหาที่แก้

คนที่จัดพอร์ตเองต้องเลือกระหว่างสองทางที่ไม่ดีทั้งคู่ — ทำเองในตารางคำนวณ ซึ่งผิดง่ายมากโดยเฉพาะ
เรื่องปันผลและการปรับสมดุล หรือใช้เครื่องมือต่างประเทศที่ตัวเลขถูกแต่อ่านไม่ออกถ้าไม่ได้เรียนสายการเงินมา
และไม่รองรับสินทรัพย์ไทย

folio-lab เลือกทางที่สาม: **ตัวเลขระดับเดียวกับเครื่องมือมาตรฐาน แต่มีคำอธิบายภาษาไทยกำกับทุกค่า**
และวางสถาปัตยกรรมให้เพิ่มกองทุนไทยกับหุ้น SET ได้โดยไม่ต้องแก้เครื่องคำนวณเลย

## ตอนนี้ทำอะไรได้

- ตั้งพอร์ตกี่สินทรัพย์ก็ได้ (สูงสุด 10) กำหนดน้ำหนัก เงินตั้งต้น ช่วงปี และตัวเทียบ
- ผลลัพธ์ 4 ส่วน: ตารางสรุป 9 ค่าเทียบตลาด · เส้นมูลค่าพอร์ต (สลับสเกลลอการิทึมได้) ·
  ผลตอบแทนรายปี · ช่วงขาดทุนพร้อมเวลาที่ใช้ฟื้น
- ศัพท์การเงินทุกคำมีคำอธิบายไทยกดดูได้ตรงจุด (Sharpe, drawdown, ความผันผวน ฯลฯ)
- ค่าที่ตั้งอยู่ในลิงก์ — ก๊อปส่งให้ใครก็เห็นผลเดียวกัน ไม่ต้องสมัครสมาชิก ไม่เก็บข้อมูลผู้ใช้
- สลับไทย/อังกฤษ และโหมดสว่าง/มืด · ใช้บนมือถือได้

## วิธีสร้าง (สิ่งที่โปรเจกต์นี้ตั้งใจแสดง)

โปรเจกต์นี้เป็นผลงานตัวอย่างของการทำ product ด้วย AI แบบมีวินัย ไม่ใช่การไล่เขียนโค้ดให้เสร็จ ๆ

### 1. เขียนสเปกก่อนเขียนโค้ด และสเปกต้องทดสอบได้

11 story card เขียนครบก่อนแตะโค้ดบรรทัดแรก แต่ละใบมีกฎทางธุรกิจที่ระบุค่าจริง เกณฑ์ยอมรับแบบ
Given/When/Then กรณีขอบ และแผนตรวจสอบ — เขียนเสร็จแล้ว **ตรวจทานแบบปฏิปักษ์** เจอ 21 จุดที่ต้องแก้
โดยสี่จุดเป็นระดับที่จะทำให้ชุดทดสอบล้มโดยที่โค้ดไม่ผิด เช่นกำหนดให้ใช้อัตราคงที่ตัวเดียวไปเทียบค่าอ้างอิง
สี่ค่าพร้อมกัน ซึ่งเป็นไปไม่ได้ทางคณิตศาสตร์ — **ทั้งหมดเจอตอนยังเป็นกระดาษ ราคาถูกที่สุด**

### 2. ความถูกต้องของตัวเลขพิสูจน์ด้วยของจริง ไม่ใช่ความรู้สึก

เก็บผลของพอร์ตเดียวกันจาก Portfolio Visualizer มาเป็นชุดอ้างอิง แล้วบังคับให้เครื่องคำนวณของเราตรง
ภายใน ±0.1% ทุกค่า — CAGR, ความผันผวน, Sharpe, Sortino, ช่วงขาดทุนทั้ง 5 อันดับ

จุดที่น่าสนใจคือค่าเดียวที่ไม่ตรง: เดือนที่พอร์ตฟื้นจากวิกฤตโควิด เราได้ ก.ค. 2020 ต้นแบบบอก ส.ค. 2020
ตรวจแล้วพบว่าเดือนนั้นพอร์ตข้ามจุดสูงสุดเดิมไปเพียง **0.0034%** ซึ่งเล็กกว่าความต่างปกติของราคาระหว่าง
ผู้ให้บริการข้อมูลสองเจ้า จึงตัดสินใจ **ไม่ปรับสูตรให้เข้ากับต้นแบบ** เพราะนั่นคือการจูนเครื่องคำนวณ
ให้เข้ากับข้อมูลเจ้าหนึ่ง แล้วจะผิดเมื่อเปลี่ยนแหล่ง — บันทึกเหตุผลไว้เป็นการตัดสินใจถาวร

### 3. แยกชั้นให้เปลี่ยนของข้างล่างได้โดยข้างบนไม่รู้ตัว

```
หน้าจอ  →  เครื่องคำนวณ (ฟังก์ชันบริสุทธิ์)  →  ชั้นข้อมูล  →  คลัง  →  แหล่งข้อมูลภายนอก
```

กฎเหล็กสามข้อ: หน้าจอห้ามคำนวณค่าทางการเงินเองแม้แต่ค่าเดียว · เครื่องคำนวณห้ามแตะเครือข่าย
นาฬิกา หรือค่าสุ่ม (มีชุดทดสอบบังคับ) · แหล่งข้อมูลทุกเจ้าอยู่หลังสัญญาเดียวกัน

ผลตอบแทนของกฎนี้เห็นจริงสองครั้ง: ตอนแหล่งข้อมูลหลักใช้ไม่ได้กลางคัน สลับไปอีกเจ้าโดยแก้ไฟล์เดียว
และตอนสลับจากข้อมูลจำลองเป็นข้อมูลจริง หน้าจอทั้งหมดไม่ต้องแก้เลยแม้แต่บรรทัดเดียว

**คลังข้อมูลเก็บผลตอบแทน ไม่ใช่ราคา** — เพราะราคาที่ปรับปันผลแล้วของอดีตเปลี่ยนได้ทุกครั้งที่มีปันผล
รอบใหม่ แต่อัตราส่วนระหว่างสองเดือนไม่เปลี่ยน เก็บราคาแล้วบอกว่าถาวรคือบั๊กที่รอวันแสดงตัว

### 4. ประตูออกคือหลักฐาน

การ์ดขึ้นสถานะเสร็จได้ต่อเมื่อ: ตรวจรูปแบบ ตรวจชนิด ชุดทดสอบ และการ build เขียวครบ · เดินหน้าจอจริง
กดทุกปุ่มที่การ์ดพูดถึงพร้อมเก็บภาพ · บันทึกสิ่งที่ทำลงในการ์ด

ตัวเลขปัจจุบัน: **144 ชุดทดสอบย่อย · 48 การเดินหน้าจอบนข้อมูลจำลอง · 6 การเดินบนเครื่องจริงด้วยข้อมูลจริง**
· ภาพหลักฐานทุก session เก็บไว้ใน `artifacts/evidence/`

### 5. ทุกการตัดสินใจมีที่มา

`docs/product/decision-log.md` เป็นบันทึกแบบเพิ่มอย่างเดียว 10 รายการ — เปลี่ยนใจต้องเขียนรายการใหม่
ไม่ใช่แก้ของเก่า ทุกกฎในโค้ดสาวกลับไปหาเหตุผลได้ว่าทำไมถึงเป็นแบบนั้น

<summary>English summary</summary>

**folio-lab** is a portfolio backtesting tool with Thai-first explanations, built as a case study in
disciplined AI-assisted product work.

Specs before code (11 story cards, adversarially reviewed — 21 issues caught on paper, 4 of them
severe enough to make the test suite unsatisfiable). Numbers proven against Portfolio Visualizer
within ±0.1%, including a documented decision **not** to tune the formula when one value differed by
0.0034% — that would fit the engine to one data vendor and break it on the next.

Strict layering (UI → pure engine → data layer → cache → providers) proved its worth twice: swapping
the primary price source took one file, and switching the whole app from fixtures to live data
required zero UI changes.

Evidence-gated delivery: 144 unit tests, 48 UI walks on fixtures, 6 on production with live data,
screenshots per session, and an append-only decision log.

Live at <https://folio-lab-gamma.vercel.app>
